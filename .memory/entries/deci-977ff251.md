User decisions (2026-10-29):

1. Frame members are checked for the wind and seismic strength combinations, not only the gravity envelope. With walls and frame in one model the frame carries its stiffness share of lateral force.
2. Phase 7 picks reinforcement per pier: cheapest passing rho_l, rho_t from a discrete list, scanned (not bisected; phi can drop as rho_l rises). Reinforcement does not change model stiffness, so the choice is exact for a given thickness. Thickness, length, and layout search stay Phase 10.
3. The wall step runs inside `_size_beams_columns!`'s fixed-point loop. Convergence tracks column and wall demands.

Finding: gravity beams default to `lateral_role=:gravity` but steel/concrete beams and girders resolve to (:fixed, :fixed) releases (`default_release` in StructuralSizer materials). So the 'gravity' frame already acts as a moment frame in the unified model. The declared seismic system (and its R/Cd/Omega0 and detailing) must match how the frame is modeled. Open question for the user.
