# What: which design codes are implemented, and where

**AISC 360-16 (steel)** — `members/codes/aisc/`: W-shape flexure/LTB (`i_symm/flexure.jl`: get_Lp_Lr, get_Mn), shear, compression, slenderness, DG9 torsion; HSS rect + round (`hss_rect/`, `hss_round/`); tension (Ch D), P-M and P-Mx-My interaction (Ch H, `generic/interaction.jl`), B1/B2 amplification (App 8), composite beams (Ch I, `composite/`). MIP checker `AISCChecker` in `checker.jl`.

**ACI 318 (concrete, primarily 318-11 with 318-19 cross-refs)** — shared math in `codes/aci/` (material_properties, whitney, deflection, punching, pca_tables, fire). RC beams `members/codes/aci/beams/` (flexure incl. doubly + T-beams, shear/stirrups, torsion, serviceability; `ACIBeamChecker`). RC columns `members/codes/aci/columns/` (P-M diagrams rect + circular, slenderness magnification, biaxial Bresler/PCA contour; `ACIColumnChecker`). Flat plates/slabs `slabs/codes/concrete/flat_plate/`: three analysis methods **DDM** (`analysis/ddm.jl`), **EFM** (`analysis/efm.jl`, builds an Asap frame), **FEA** (`analysis/fea/`, Wood-Armer + section cuts), design pipeline `flat_plate/pipeline.jl` (Phases A/B/C), punching reinforcement `flat_plate/studs/`.

**fib Model Code 2010 (FRC shear)** — `members/codes/fib/frc_shear.jl` (Eqs 7.7-5/7.7-6, §5.6.4 linear model).

**PixelFrame (ACI 318 + fib MC2010 + thesis)** — `members/codes/pixelframe/`: axial/flexure with external PT, deflection, carbon, per-pixel material assignment; `PixelFrameChecker`.

**NDS (timber) — stub only** (`members/codes/nds/checker.jl`, limited).

**Foundations** — `foundations/codes/`: ACI 318-11 spread + strip footings, ACI 336.2R-88 mat (rigid / Shukla AFM / Winkler FEA), IS-code spread footing, strategy heuristic.

**Other:** ASCE 7-22 combinations; ACI 216.1 fire; analytical Haile vault. Eurocode is stubbed/commented for the future.
