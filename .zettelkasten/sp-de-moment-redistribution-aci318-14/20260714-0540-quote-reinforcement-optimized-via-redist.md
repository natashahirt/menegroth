# Quote: reinforcement optimized via redistribution vs spBeam

The required reinforcement areas are determined for this continuous beam after analysis are adjusted and optimized
using moment redistribution provisions from ACI 318 standard. The results of hand calculations are then compared
with numerical analysis results obtained from the spBeam engineering software program by StructurePoint.
