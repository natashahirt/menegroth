# Shear walls & lateral-force-resisting system (LFRS)

**Motivating finding (2026-07-12).** menegroth is **gravity-only** today. Wind/seismic load combinations are *defined* (`StructuralSizer/src/loads/combinations.jl`) but never populated with nonzero W/E; `to_asap!` assembles a **frame-only** model and applies only downward tributary loads; diaphragm shells are *created but never assembled* into the solved model; `story_properties.jl` has `Vus`/`Δo` slots filled by gravity FEM or 5%-of-ΣPu / 0.5-in fallbacks; and `StructuralSizer/src/walls/_walls.jl` is **empty**. Asap itself is capable (validated `ShellTri3` membrane+bending, a `Diaphragm` helper, P-Δ on mixed frame+shell models) but menegroth uses shells only for *horizontal* slabs/vaults.

So shear walls are not merely a new member type - they are the visible tip of a **lateral subsystem that does not yet exist**. This program builds it in scope tiers so the first step stays dev-loop-sized while the larger architecture is worked out.

## Scope ladder
- **S1 (ACCEPTED, active pilot) - Wall element + ACI checker, demand-as-input.** Add `Wall{T} <: AbstractMember{T}`, an ACI 318 shear-wall checker, and a report; per-wall `Vu/Mu/Pu` are supplied as inputs (or a trivial hand distribution). Small, canon-rich (corpus already has spWall worked examples), and defers the lateral-analysis question. See `todo-w0000002`.
- **S2 - Rigid-diaphragm lateral distribution.** Generate wind/seismic story forces + distribute to walls by relative rigidity, incl. skew projection and torsion about the center of rigidity. Closed-form; also the known-answer oracle for S3. See `todo-w0000003`.
- **S3 - FEM lateral (Asap shells).** Mesh vertical walls as `ShellTri3` sharing nodes with floor diaphragms, wire shells into `Asap.Model` (currently dropped), apply story lateral loads, recover in-plane `Nxy/Mxx`. Handles skew/torsion natively. See `todo-w0000004`.
- **S4 - Layout optimization.** Synthesize wall placement (Zhang & Mueller 2017, MIT - `corpus_id: zhang-mueller-2017-shear-wall-layout-opt`). Synthesizer-level. See `todo-w0000005`.

## Architecture fit (StructuralSynthesizer)
`Wall{T} <: AbstractMember{T}` = plan line segment (`center,length,θ` or endpoints) + `thickness` + `height (=L)`, per-story, stacked like columns (`wall_above`); skew is already representable (skeleton supports arbitrary-angle edges). Needs a `:walls` edge group in `APIEdgeGroups`, an `initialize_members!` branch, `BuildingDesign.walls::Dict`, and - the real gap - a **lateral pipeline stage** (generate demand -> distribute/analyze -> size walls -> drift/overturning) that also finally assembles the diaphragm shells.

## Placement policy
menegroth's invariant is *placement is input, design only sizes* (columns/beams come from skeleton edge groups; face-finding/tributary run after placement). Walls follow the same rule: **given** (S1-S3, a `:walls` edge group), with **heuristic** (core + symmetric perimeter to align center of rigidity with center of mass) and **optimized** (S4) as later modes. Position is carried as data on `Wall` so all three share one downstream sizing/analysis path.

Efficiency of the layout search (S4) is a first-class concern from the start - see decision `deci-w0000006`.
