# Epoch 3 - Tributary-area engine (2026-01-17 .. 2026-01-22)

A concentrated, visibly hard-won push to compute **load tributary areas** from arbitrary floor-plate geometry - the bridge from geometry to member loads. The commit trail reads like a debugging diary: isotropic trib works (`3cd947c2`), convex-shape tolerance + non-convex warnings (`7a1fe2da`), hole/overlap/ownership fights on regular polygons (`ed49d565`), then the breakthrough **"aaah trib area works!"** (`fb28c364`, 01-20).

The robust solution is a **DCEL** (doubly-connected edge list): "dcel with same func as original" (`5a515c4e`) and **"dcel resolves octagon bug! it looks great"** (`8b87ccc7`). Then **one-way / one-directional** tributary areas (`613f3cb1` .. `9ec3af20`, 01-21) and integration into Asap + AsapToolkit so the **sizer now consumes these loads** (`21969292`), reaching **"full end to end"** (`c7c0af64`, 01-22). Column tributary areas via **Voronoi** follow in Epoch 4.
