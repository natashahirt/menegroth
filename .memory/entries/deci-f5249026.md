The .mgscene packet now carries three analysis fields the viewer already had menus for, taken from the quantities the solver already computes.

- `shell_surface_stress` is one f32 per shell triangle, the same signed dominant principal surface stress as JSON `face_surface_stress` (Pa, tension positive), from `ShellInternalForces`. Written only when nodal displacement is assigned. `max_surface_stress_pa` is the largest absolute value.
- `element_axial` is one signed f32 per frame element (N, tension positive), the station of `ElementInternalForces` with the largest absolute axial force. `max_axial_n` matches. Omitted when the solved stage is not requested.
- Tributary loops (`tributary_position`, `tributary_count`, `tributary_element`, `tributary_kind`) come from cached column polygons and, for beams, `Asap.vertices` of each cell-edge `TributaryPolygon` on the face-vertex edge. Kind 0 is a column, 1 is a beam. An empty cache writes nothing. Walls are not included.

The viewer colors shells and sticks with the deflection ramp centered on zero, and draws tributary fills (cerulean columns, gold beams) 20 mm above the slab. A buffer that is present but the wrong length throws. A scene written before these buffers still says the field is not in the scene. The office file on disk is unchanged until the next `build_scene`.
