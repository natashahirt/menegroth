# Parameters kc, h, λ, λpf, λrf for F3.2

kc = 4/sqrt(h/tw), bounded 0.35 <= kc <= 0.76; h per Section B4.1b; λ = bf/2tf; bf/tf = flange width/thickness; λpf = λp (compact-flange limit, Table B4.1b); λrf = λr (noncompact-flange limit, Table B4.1b).
