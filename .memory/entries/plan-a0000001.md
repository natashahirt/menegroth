# Codebase architecture & reasoning

This subproject is the human/agent-readable map of the menegroth code: one phase per package, with typed entries beneath capturing the **what** (responsibilities, key types, entry points), the **why** (design decisions, invariants, conventions), and the **how** (control/data flow, the sizing pipeline, the design codes implemented).

The live *structural* code graph (functions/classes/modules) is built automatically by angelo's memory server via `codebase()` once it runs in-editor; this tree carries the reasoning that a symbol graph cannot.

Dependency chain: **Asap -> StructuralSizer -> StructuralSynthesizer**, with Plots/Visualization/Studies on top.
