# Flexural Reinforcement As, a, c and Strain Check (Test Oracle)

Required steel As = 3.16 in²; recomputed depth of stress block a = 3.48 in; neutral-axis depth c = a/β1 = 3.48/0.85 = 4.10 in; net tensile strain εt = (0.003/c)(dt) − 0.003 = 0.0127 > 0.005, confirming the tension-controlled assumption.
