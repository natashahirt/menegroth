# Why: the code<->document citation contract (central to goal c)

StructuralSizer follows the corpus citation contract (`.cursor/rules/corpus.mdc`). Capacity-code comments carry, by convention:
1. **Standard + edition + clause/equation** — e.g. `ACI 318-11 §11.2.1.1`, `AISC 360-16 Eq. F2-5`.
2. **`corpus: <source_id>, page N`** — a link to a promoted corpus entry, e.g. `# Ec: ACI 318-11 §8.5.1 (corpus: aci-318-11, page 115)`.
3. **`ENGINEERING JUDGMENT:`** — explicit non-code defaults that must not masquerade as clauses (e.g. AISC composite flange default `b = c1_avg`).
4. **`reference/`** dirs (e.g. `members/codes/aisc/reference/`) holding upstream PDF clause extracts.

Primary edition is **ACI 318-11** clause numbers (318-19 numbers appear as preservation notes, esp. PixelFrame and punching §22.6). fib citations name section + equation (`§7.7.3.2.2`).

**This convention is the seam for synapse:** these `(source_id, page, clause)` references are exactly what a zettelkasten `claim`/`quote` note is keyed on, so `implements` edges (code -> clause) can be minted from the comments once the corpus is re-extracted. See the plan doc §5.
