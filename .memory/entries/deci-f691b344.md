Resolved the three residual critic P2s from the Guard-F2 P0 fix.

**P2-2 (real change) - endpoint-aware enclosure.** `_plate_encloses_walls` (lateral_evaluator.jl) now accepts an OPTIONAL id->half-length map `wall_half_lengths::Union{Nothing,AbstractDict{Int,Float64}}=nothing` (candidate id -> lw/2), built in layout_problem.jl via `_candidate_half_lengths(p)=Dict(c.id=>c.lw/2)`. It is threaded from the optimizer alongside the existing active-ID set through evaluate_lateral / direction_complete_interstory_drift / eigenstructure_stability / _evaluate_lateral_or_singular / _eigenstructure_or_singular to all three per-story call sites + the solve_wall_layout gate + survivor re-validation. When supplied, each active wall's BODY is checked with the endpoint EXTENSION gated PER-AXIS on positive plate half-extent: the X bound-check tests {w.x +/- hl*cos(theta)} only if hx>0 (else centroid w.x), symmetric for Y on hy.

- On a NORMAL plate (hx>0 AND hy>0) this is mathematically identical to requiring BOTH endpoints inside the convex rectangle -- strictly more conservative than the old centroid-only test.
- On a DEGENERATE axis (hx==0 or hy==0) it reverts to the centroid for that axis, preserving the crit7 thin-plate contract.
- Default `nothing` = centroid-only: the one-shot CHECK path + FEM tier are byte-for-byte unchanged. WallLine carries no length, so the endpoint test is optimizer-path-only by data-model constraint.

**P0 REGRESSION caught + fixed mid-session (key design point).** The FIRST implementation checked both full endpoints against both axes UNCONDITIONALLY, which REGRESSED the crit7 zero-half-extent (thin-plate) contract: the near-dead-Y / crit4 fixtures legitimately declare `plan_halfwidth=(0,5)` (hx=0) with theta=0 lw=4 X-walls whose centroids sit on x=0 but whose bodies extend to x=+/-2. The both-endpoints test flagged them as overhanging -> :geometry_inconsistent, short-circuiting the intended :Y drift verdict and breaking 4 pre-existing assertions. Fixed by the PER-AXIS gating above. Both the critic and tester caught this in round one.

**P2-1 (doc).** Documented in `_active_candidate_ids` that activity is judged on the DIMENSIONLESS penalized fraction rho^penal, which assumes per-candidate k_max is non-pathological; absolute-stiffness / occupancy questions are delegated to the Phase-10 FEM survivor. EXPLICITLY REJECTED the critic's suggested `k_i < 1e-6*sum(k)` gate -- that is the relative-stiffness trap: one stiff inside wall inflates sum(k) and masks a real outside wall -> fail-open.

**P2-3 (doc).** Corrected the empty-after-mask backstop comment in `_plate_encloses_walls` to name the LOAD-DEPENDENT eigenstructure translational floor `util_trans` as the governing backstop for a loaded all-masked story (the scale-invariant singular/rcond guard alone would not catch a uniformly-softened-but-well-conditioned story).
