# S2 - Rigid-diaphragm lateral distribution

Give walls a real demand without full FEM.

- Generate lateral story forces: wind (ASCE 7 directional/MWFRS) and seismic (ELF base shear + vertical distribution). Populate the W/E load cases that `combinations.jl` already defines but never fills.
- Distribute each story shear to walls by **relative rigidity**, decomposing each wall's in-plane stiffness onto global X/Y (skew wall resists the projected component), plus a **torsional** term about the center of rigidity (needs center of rigidity vs center of mass, accidental eccentricity).
- Feed the resulting per-wall `Vu/Mu/Pu` into the S1 checker.
- Add drift/overturning checks; populate `story_properties.jl` `Vus/Δo` for real.

Closed-form and O(walls) - cheap enough to be the **inner-loop evaluator for S4** and the **known-answer oracle for S3**. See `deci-w0000006`.
