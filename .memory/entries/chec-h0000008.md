# Epoch 7 - LLM assistant & trace infrastructure (2026-03-25 .. 2026-03-31)

menegroth gains an **AI design-assistant layer** and the explainability plumbing to support it:

- **Assistant layer for the API + Grasshopper**, hardened tool calls, made to "actually work" (`4aeb7c9d`, `14bb1809`, `d4223e4b`, 03-25).
- **Trace infrastructure** (`8cee1136`, 03-26): full trace instrumentation across the design pipeline, a **tiered trace serializer for LLM use** (`56cf2de1`), situation cards + reasoning guidelines (`72bd28d8`), a **unified assistant** (`a78e41b4`), and post-hoc **breadcrumb bundles + `explain_trace_lookup`** microscope (PR #17).
- LLM quality work: richer geometry description + reasoning over geometry, tool compaction, ontology refinement, **removing hallucination patterns**, stricter parameter space (03-28/03-29).
- **Micro-experiments suite** for the agent, a **lever map**, run-to-run comparison, Inf guards, and "column sizes stay the same across floors" (`66caebaf`, 03-30) - encoding real engineering heuristics for the AI.

This is the origin of the why/what/how reasoning surface the angelo memory graph now aims to capture natively.
