# Decision - Unitful integration & `StructuralUnits` (2026-01-17)

**Context.** Structural engineering mixes unit systems (kip, ksi, ft, in, kN/m...) and unit errors are dangerous. Commit `ce0daf8d` delivered **"full asap/asaptoolkit unitful integration"** and created **`StructuralUnits`** to "give custom units and prevent weird integration issues."

**Rationale.** Adopting Unitful end-to-end makes dimensional correctness a compile/runtime invariant rather than a convention, and the custom unit layer smooths friction between Asap's internals and the sizing code. **Consequence:** later deployment bugs like the `KipPerSquareInch` KeyError (`f33ba858`, 03-13) and "move `using Unitful` to top level" (`1daa8f33`) trace directly back to this pervasive unit dependency, especially on the precompiled async server.
