# Minimum depth to waive deflection computation (9.8.2.1 / Table 9.2)

Because the chosen depth h=610 mm exceeds the Table 9.2 cantilever minimum (ln/8 = 312.50 mm), deflection computations are not required per 9.8.2.1.
