`_create_offset_nodes` (StructuralSynthesizer/src/analyze/asap/utils.jl:16) builds every non-support frame node with dof = [true,true,true,false,false,false]: all three rotations fixed. Present since the first Asap model (commit 1fed50346, Jan 2026), copied through every refactor; never documented as intentional. Docstrings in the same file say (u_z, θx, θy) 'stay free'. A Phase 9b fix (`_free_plan_rotation_for_rigid_diaphragm!`) frees only θz, only for :rigid diaphragms. Wall/slab mesh nodes are created :free; frame nodes reused by the wall mesh keep the lock.

Asap side is ready: released elements have stiffness (k_fixedfree/k_freefixed/k_freefree/k_joist in external/Asap/src/Elements/K.jl) and fixed-end forces are release-aware (Loads/fixed_end_forces.jl), so pinned members send simple-span reactions, not fixed-end moments. The Phase-7 smoke comment about undefined k_* is stale.

Measured (scripts/runners/check_node_rotation_lock.jl; 3x3 bay, 3 story, 20 ft bays, placeholder W10x22 frame; log logs/check_node_rotation_lock.log):
- Fixed beam ends, gravity: locked -> beam end M 133 kN·m, column M 0. Freed -> beam 147, column 72 kN·m.
- Lateral 10 kN per roof node: locked -> roof drift 6.8 mm regardless of beam fixity, beams carry 0 moment. Freed fixed beams -> 17.8 mm. Freed pinned beams -> 245 mm (cantilever columns).
Consequences: columns (sized from frame forces via member_group_demands) get no moment from unbalanced beam end moments; frame lateral stiffness is overstated (2.6x for moment frame, ~36x for pinned frame); in a walls-as-SFRS unified model the frame steals lateral load.

Second finding: release material in to_asap!/build_analysis_model! is `materials.beam` or `materials.steel` (both steel-only; default nothing -> fixed), while sizing uses `something(params.beams, SteelBeamOptions()).material` (default A992). Default buildings size steel beams but analyze them fixed; a concrete-beam design with materials.steel set would analyze pinned.

Proposed fix (awaiting user): free all rotations on non-support frame nodes, but keep a rotation fixed at a node where no connected element has a fixed end and no shell attaches (exactly equivalent, avoids singular K); subsume the θz-only rigid-diaphragm patch; resolve release material from the beam sizing options.
