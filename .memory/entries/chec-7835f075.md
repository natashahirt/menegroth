Added `linear_response(model, f; links)` to Asap: full displacement response u = K⁻¹ f to an arbitrary nodal load, reusing the cached (reduced-aware) stiffness factor — one back-substitution, no refactorization. Rigid-diaphragm models route f through Gᵀ, solve the reduced factor, recover through G. Reuses the same `_participation_reduction`/`_virtual_fields` machinery as drift_participation.

This is the accelerator primitive for the strength↔drift coupling: under fixed external load, a resize ΔK shifts displacement by Δu ≈ -K⁻¹(ΔK u) = linear_response(model, -ΔK*u; links), so the governor can predict redistributed member demands at proposed sizes WITHOUT a fresh solve (one extra RHS, like the virtual-load solve). ΔK_e comes from Asap's existing non-mutating `global_K(element)` at a trial section.

Tests (Asap 40/40, was 35): real-load reproduction (linear_response(model, P-Pf) ≈ model.u) on both the plain and rigid-diaphragm models; first-order resize prediction verified against an exact perturbed re-solve (two columns differing only in element-1 inertia, ε=1e-3, first-order error < 1% of the step).
