Column orientation and slab span direction stay independent. The building plan axis is only the default for both.

- `Column.θ` is the column orientation (c1 from global X). `initialize_members!` sets it from `LateralDesign.plan_axis` (0 when the axis is global X). The Asap roll in `to_asap!` is derived from `Column.θ`, added to Asap's default Ψ, so θ = 0 leaves every existing model unchanged. Slab span axes do not set θ.
- One-way span direction, in order: `ScopedFloorOverride.span_axis`, then `DesignParameters.tributary_axis` when it is a direction, then the short side measured on the plan axes. Any bay shape is allowed. A direction recomputes that cell's `SpanInfo` and is what load routing uses.
- `assert_story_walls_enclosed!` tests wall centers against the story's floor faces. The axis-aligned plate box remains the drift plate (`story_plate_geometry` / `assert_walls_enclosed`).
- Parallelogram tests pass an explicit span axis three ways: along the sheared edge, perpendicular to it, and along global X.

Known, not changed: at θ = 0, Asap's default Ψ = π/2 makes `Ix` (h = c2) resist global-X sway, while c1 is the X dimension. Fixing that would rotate every existing column section by 90°.
