# Decision - Asap as an external git submodule (2026-01-16 / 2026-03-06)

**Context.** Asap (the FEA engine + Unitful units) is a separable, independently authored dependency (author Keith JL). Early on it was **moved to its own folder with its own git structure** (`03783a03`, 01-16). During productization the repo briefly removed `./external/Asap` (`ecfe334a`) then re-added it as a **git submodule so "asap is visible"** (`2c7d7166`, 03-06).

**Rationale & consequence.** Keeping Asap as a submodule under `external/` lets menegroth track a specific Asap revision while Asap evolves on its own history, and keeps the FEA core decoupled from the sizing/synthesis stack. Docker builds and the `git status` `m external/Asap` marker both stem from this choice.
