Implemented the column-width, span-side section cut (_span_side_cut) and capped the default FEA target edge at 0.30 m. Column-patch stiffness default is still 1.0; the rigid case was run with patch_stiffness_factor=100.

Comparison runner scripts/runners/compare_fea_section_cut.jl on the StructurePoint 18×14 ft, 3×3 bay floor (h=7 in, 16 in columns, qu=193 psf). Log: logs/compare_fea_section_cut.log.

Long span (StructurePoint's table, M0 target 93.82 kip-ft):
- DDM: M0 93.5, M-ext 24.3, M+ 48.6, M-int 65.5. Coefficients 0.26/0.52/0.70. Matches the published end-span moments.
- EFM: 30.3 / 49.8 / 88.3 (0.32 / 0.53 / 0.94).
- FEA flexible (default patch): 47.4 / 57.2 / 54.4.
- FEA rigid, default mesh: 48.2 / 47.0 / 54.7.
- FEA rigid, 0.15 m: 53.1 / 45.2 / 58.2. Edge Mub 42.7 vs 42.5 (rigid default vs 0.15 m). Face moments differ by up to 9% (exterior negative).

Short span M0=69.5. DDM again 0.26/0.70/0.52. Rigid vs 0.15 m within about 5%.

Rigid vs flexible edge-column transfer moment is about 1.5× (long span 42.7 vs 27.8 kip-ft). Panel deflection 4.72 mm → 3.38 mm.

FEA positive moment matches DDM's 0.52 factor. FEA exterior negative is about twice DDM's 0.26 factor. Strip check (M-ext+M-int)/2+M+ is within a few percent of M0 for rigid FEA on the short span and about 5% high on the long span.
