# Averaged Ie for end span (spBeam Eq. 2-104)

Weighted average effective inertia for an end span. LaTeX: \( I_{e,avg} = 0.85\,I_e^{+} + 0.15\,I_e^{-} \). Symbols: \(I_e^{+}\) = Ie at midspan (positive region), \(I_e^{-}\) = Ie at the continuous-support negative region. Worked: Ie,avg = 0.85×7,561 + 0.15×10,919 = 8,065 in⁴. (Source: spBeam Manual v5.00 Eq. 2-104.)
