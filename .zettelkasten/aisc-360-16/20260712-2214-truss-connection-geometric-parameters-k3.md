# Truss-connection geometric parameters (§K3.1)

Truss-connection geometric parameters (§K3.1): θ = acute angle between the branch and chord; β = width/diameter ratio of branch to chord; γ = chord slenderness; η = load-length parameter; ζ = gap ratio; g = gap between the branches of a gapped K-connection; O_v = overlap ratio.
