# Decision - trace infrastructure for explainability (2026-03-26)

**Context.** To let an LLM assistant *explain* and *steer* structural design (Epoch 7), the pipeline needed to expose why each decision was made. Commit `8cee1136` "added trace infrastructure", refined into **full trace instrumentation across the design pipeline** (`995ebb22`), a **tiered trace serializer for LLM use** (`56cf2de1`), and **breadcrumb bundles + a post-hoc `explain_trace_lookup` microscope** (PR #17).

**Rationale.** A tiered serializer keeps token budgets manageable while still letting the model drill into any decision; "register pipeline decisions" (PR #22) threads a trace context (`tc`) through foundations/floor optimization. **This is the conceptual predecessor to the angelo memory graph** - the same why/what/how reasoning, now captured in a persistent knowledge graph rather than per-run traces.
