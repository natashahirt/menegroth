The §I3.1b check stays on the existing construction path (SEI/ASCE 37-02 §2.2.3 Eqs. 2-2 and 2-3). It no longer keeps a separate shape source.

After a bay is split, beam_pre_cure_shape reads the child elements that carry the tributary loads. The parent edge is zero stiffness and is not the shape. Moments are recovered inside the same bare-steel section swap the unshored stage uses, while that section's K is still on the element. Reading the steel displacement back through the composite stiffness is a different moment; stiffening the children does not change the pre-cure moment.

A released beam's children are not all the parent's release. _retarget_element_loads! widens a load vector whose element type is one release so the split loads fit. Lists that already accept every load are left as they are.

A constant width still scales one dead-load shape by w/w_ref. A width that varies at one pressure keeps the solved shape: the area-load part scales by pressure, and the steel self-weight, C_D, and C_FML scale a unit line-load shape from that same steel solve. A load that is not one tributary pressure still falls back to the simple span.

The subdivided mesh is the moment the rest of the composite path already uses. It is not a replay of the unsplit element.
