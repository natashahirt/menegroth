# Live-load arrangement — full factored L on all spans (§6.4.3.2)

Because unfactored live load does not exceed three-quarters of unfactored dead load (L/D = 0.25 < 3/4), ACI 318-14 §6.4.3.2 permits design moments at all critical sections to be taken with full factored live load on all spans (no patterning). Clause 6.4.3.2, page 9.
