One open floor of the core office (z = 3.6 m, h = 10.5 in from Table 9.5(c) on the 8 m bay) was run with the equivalent frame and the shell. Direct design remains refused: the shortest frame has two spans (§13.6.1.1, page 252) and one panel is 24 m by 8 m (§13.6.1.2). The core-shaft suite still records that refusal (1140/1140).

Two defects had to be fixed before the frame and the shell would solve. A column on the story above with no section yet uses the section of the column below. A frame whose centerline is the slab edge was dropped, because the inside test counts one side of a rectangle in and the opposite side out. The edge now counts as slab. A point in the opening does not.

Same total static moment, 595 kip-ft. Positive moment: frame 310, shell 321. The shell's largest column negative is 188 kip-ft. Every column on this floor is an edge column, so the shell files that moment as exterior and reports no interior-column negative. The frame's end-of-line negative is 140 kip-ft. Its largest negative is 627 kip-ft, at a joint that is interior to the column line and still on the building edge.

Runner: scripts/runners/core_office_open_floor_moments.jl. It does not design the building and does not write a scene.
