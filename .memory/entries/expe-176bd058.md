## What was measured
Frozen-geometry probe (`scripts/runners/probe_fixed_mesh_accuracy.jl`): one medium-office floor (8x5 bays, 54 columns), columns frozen at a single size and h=10 in, then `run_moment_analysis` run under conforming remesh `FEA()` vs fixed mesh `FEA(fixed_mesh=true, fixed_mesh_cap=30in)`. Per-column punching DCR via the pipeline's own `check_punching_for_column`, face moment M- via `moment_results.column_moments`. Swept column sizes 14/18/22/26 in. A **noise-floor** row compares the default remesh vs the SAME conforming method at a finer target edge (0.18 m) — the remesh's disagreement with itself.

## Key numbers (max |drift|, corner punching DCR)
| col | noise floor (remesh vs remesh-finer) | fixed-mesh drift |
|---|---|---|
| 14in | **15.71%** | 16.10% |
| 18in | 2.77% | 3.17% |
| 22in | 1.53% | 3.62% |
| 26in | 3.33% (interior) | 4.00% |

Face M- noise floor at edges = ~81% (remesh vs itself) — the '100%' fixed-mesh number was always the near-zero free-edge baseline artifact (a true flat plate has a free perimeter, so edge face moment ~ 0; dividing by ~0 explodes the %). Interior columns: both small (<=4%).

## Conclusion
Corner punching Mub and edge face moments are inherently mesh-noisy (~15% / ~80%). The production conforming remesh **violates the +/-2% / +/-3% per-column band against itself**, so that band was the wrong acceptance gate. The fixed mesh sits right at that noise floor (16.1 vs 15.7 at corners), with only a small systematic bias above it at mid sizes. By the only honest standard — the method's own reproducibility — the fixed mesh is as accurate as remeshing.

## Dead ends ruled out (both measured, within noise, no benefit)
- **Cap-based edge strip** (note-4c103bb8 Phase 2): worst corner DCR 16.2% -> 8.4%, still outside band; trades patch-poke for fictitious corner overhang.
- **Hybrid** (interior cap, edge/corner conforming): corner drift 16.16% -> 16.10% (unchanged) — proving corner error is NOT from the corner's own cap patch but from mesh-noisy Mub extraction. Reverted (added complexity + lost speed for zero accuracy gain).
