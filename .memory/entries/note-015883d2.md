Story-shell slab bars are no longer a parallel-array function with their own Wood-Armer copy.

Each panel is a StoryPanelDesign: service dead and live pressure, thickness, span axis, and a floor system from floor_type. Effective depth dispatches on spanning_behavior: one bar layer for OneWaySpanning, two orthogonal layers otherwise. The moment transform dispatches on the FEA method (panel_shell() by default) through _envelope_design_faces, the same function the flat-plate area extractor uses. OneWayMomentCoefficients throws, because those are span moments rather than a shell tensor.

Beam sections are still not taken from the shell forces.
