# Epoch 1 - Origins (2025-12-20 .. 2025-12-22)

The project opens as a **geometry prototype**: `31bed803` "basic geometry for medium office plus generic visualization", then automatic **face-finding** (`2446d4f9`, `96f07af7`). This establishes the seed idea - take a building footprint/massing and automatically decompose it into the faces (floor plates, bays) that later become structural surfaces. No analysis or sizing yet; the focus is turning raw geometry into a topological description that downstream structural code can consume.
