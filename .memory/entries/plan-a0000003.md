# StructuralSizer

The largest package: materials, sections, members, and design-code checkers/optimizers. Design codes implemented include AISC 360 (steel), ACI 318 (concrete beams/columns/flat-plates via DDM/EFM/FEA), ACI 336 foundations, fib MC2010, and a `pixelframe` system. Optimization is formulated in JuMP with Gurobi / HiGHS / Ipopt backends. Carries the citation contract linking code clauses to the corpus.

_Deep entries (per design code, the checker/optimize layers, the materials/sections/members type hierarchy, the trace/feasibility machinery) attach beneath this node._
