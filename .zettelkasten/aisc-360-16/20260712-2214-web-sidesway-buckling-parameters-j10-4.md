# Web sidesway buckling parameters (§J10.4)

Symbols for the web sidesway-buckling provision (§J10.4): L_b = largest laterally unbraced length along either flange at the point of load; b_f = flange width; h = clear web depth; t_w, t_f = web and flange thickness; C_r = coefficient that depends on whether the required flexural strength at the point of load reaches the yield moment M_y (per §J10.4).
