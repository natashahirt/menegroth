Unshored composite beams are now checked as bare steel under a pre-cure line load. The final factored envelope is no longer the construction demand. Shored beams skip the check. Composite stays opt-in.

Load combinations are SEI/ASCE 37-02 §2.2.3 Eqs. 2-2 and 2-3 (corpus: sei-asce-37-02, PDF p. 16). Fresh concrete is C_VML at the finished thickness (Commentary C4.2, PDF p. 22); the 1.4 factor is the code's piling allowance, so no extra thickness is added. Steel self-weight is D. Personnel and equipment C_P is Table 2, §4.8.1.1 (PDF p. 29): 20 / 25 / 50 / 75 psf. Default is medium (50 psf) and the class is reported. Explicit nothing or an unknown class throws. C_H is omitted because it is horizontal. Finished occupancy live load is not applied as 0.5L unless the caller passes p_L.

Every construction result names 37-02 and says it is older than the ASCE/SEI 37-14 cited by AISC 360-22 Commentary §I3.1b (PDF p. 500). Chapter F is still the 360-16 implementation; that mix stays flagged.

Engineering judgment, not a code formula: the sizer does not see end releases, so M = w L^2/8 and V = w L/2 on this member's span. wL^2/8 is the largest uniform-load moment among simple, propped, and fixed ends. wL/2 is below the propped-cantilever end shear. Loaded width is the tributary extent, not b_eff and not the restuffed spacings. A deck flute is counted solid in C_VML. Deck steel weight is included only when passed in. Unshored total deflection still scales the single FEM deflection by bare Ix.

Tests (296 pass): an unshored beam whose pre-cure moment exceeds Chapter F fails and the same beam shored passes; a large final hogging face does not fail construction; explicit nothing and an unknown class throw; the default is medium and the clause names 37-02.

Code is uncommitted. The 37-02 line in corpus/manifests/sources.yml is still a separate uncommitted change.
