# PCA Simplified deflection factor K = 1.2 − 0.2(Mo/Ma)

Deflection multiplier for the PCA Simplified procedure. LaTeX: \( K = 1.2 - 0.2\dfrac{M_o}{M_a} \). Symbols: \(M_o\) = simple-span midspan moment = wℓ²/8, \(M_a\) = midspan moment at service load level. Worked (total service): K = 1.2 − 0.2×(546/216.64) = 0.696; Δtotal = 1.404 in.; ΔLL = 1.404 − 0.910 = 0.494 in. < ℓ/360 = 1.33 in. OK. (Source: PCA Notes on ACI 318-11, Table 10-3 / §9.5.2.4(3).)
