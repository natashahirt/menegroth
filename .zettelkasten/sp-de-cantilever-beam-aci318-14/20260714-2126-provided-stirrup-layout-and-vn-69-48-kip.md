# Provided Stirrup Layout and φVn = 69.48 kips (Test Oracle)

Provided stirrup spacing 10.444 in ≤ smax = 10.720 in. Design shear strength φVn = φ(Av·fyt·d/s + Vc) = 0.75(0.40×60×21.44/10.444) + 32.54 = 36.94 + 32.54 = 69.48 kips ≥ Vu@d = 33.60 kips. Use 10–#4 @ 10.444 in o.c., first stirrup 3 in from the column face.
