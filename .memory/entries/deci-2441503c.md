FEA column-face cuts keep a one-column band depth starting at the face. `averaging_width_factor` (`nothing` by default) is the transverse width in multiples of the column dimension across the span. A number averages the intensity inside that window and applies it across the strip the cut already integrates, so a narrower window raises the design moment toward the peak. `patch_stiffness_factor` now defaults to 100 (rigid footprint). The FEA pattern path in the same files uses one equivalent frame per column line.
