End-to-end building generation and structural design platform, written in Julia. Core dependency chain: Asap (finite-element analysis + Unitful units) -> StructuralSizer (code-based member/section/slab/foundation sizing and design checks: AISC 360, ACI 318, fib MC2010, pixelframe) -> StructuralSynthesizer (building-skeleton generation, the design_building workflow, an Oxygen HTTP API + agent tools, and embodied-carbon accounting). StructuralPlots / StructuralVisualization / StructuralStudies provide Makie plotting, 3D visualization, and parametric studies. A curated corpus/ of building-code PDFs (codes, guides, worked examples, research, textbooks) backs the engineering with a citation contract, surfaced today by the corpus.* MCP server and slated to be re-extracted into an angelo zettelkasten knowledge graph.
