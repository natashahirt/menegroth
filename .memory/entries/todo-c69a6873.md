User direction (2026-10-29), possibly a separate paper. Support several lateral analysis approaches selectable side by side and compare results on the same building:

1. Whole building as one unit: the unified frame-shell model, forces by stiffness (current Phase 7 path).
2. Walls sized in isolation for a stated share of the expected lateral load (e.g. 50%). An explicit, labelled mode, never a silent default (see note-8072f72a). The remainder must be carried and checked by something else, or the mode is a comparison/upper-lower bound, not a design.
3. Walls-only seismic system with gravity frame (Phase 7 option a).
4. Outrigger systems: core + outrigger/belt trusses + perimeter columns. Indeterminate; study where load most likely flows. Load share depends on relative stiffness (core cracking, outrigger truss, column axial stiffness, foundation rotation, connection timing / differential shortening). Idea: bound the load path over plausible stiffness assumptions instead of one elastic answer.

Not Phase 7 work.
