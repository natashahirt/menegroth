# Beam joint distribution factors DF (0.350 exterior, 0.150 interior)

Distribution factor DF = Kb / ΣK at each joint. Exterior joint DF = 1,298,357 / (1,298,357+1,310,872+1,111,633) = 0.350. Interior joint DF = 1,298,357 / (1,298,357+1,298,357+3,397,780+2,881,353) = 0.150. Beam COF = 0.5.
