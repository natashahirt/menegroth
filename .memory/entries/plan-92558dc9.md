When `_iterate_beams_columns!` returns to a section state it already left, stop the free loop and settle by checking.

1. Install each state in the cycle, re-analyze, and check every beam group and column group against that state's own demands. The check is the sizer's own checker: `check_tbeam_section` for concrete T-beams, and a one-section catalog for rectangular concrete and steel.
2. If any state passes completely, install the cheapest (section objective times length, beams and columns) and re-analyze.
3. Otherwise keep, per group, the cheapest section that passed in some state, or the costliest section if it passed in none. Re-analyze and re-check.
4. Groups that still fail are sized for the new demand. A state already checked is not installed again. A few rounds, then report not settled.

Service deflections stay on the frame model. The pinned-joist strength envelope still applies inside the demand used for the check. Waffle ribs are not pinned.
