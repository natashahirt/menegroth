Locked 2026-11-02. The user approved, in order: put the real beams into the shell as frame elements, so one model handles one-way support and two-way slabs on beams; add the beam cases to the existing Direct Design Method as the hand check for regular two-way bays, after the shell works; fix the two-way thickness first.

Thickness, done: `min_thickness(::TwoWay, ln; fy, beta, alpha_fm, discontinuous_edge, edge_beam_alpha_f)` implements ACI 318-11 §9.5.3.3(a)–(d) (corpus: aci-318-11, pages 134–135). New `alpha_f` (Eq. 13-3, page 253) and `alpha_fm` (notation, page 29). Before, Eq. (9-13) was used without checking αfm > 2, which is unconservative for flexible beams.

With alpha_fm = nothing, the ENGINEERING JUDGMENT bound is max(Table 9.5(c) exterior without edge beams, 1.1 × Eq. (9-12) at αfm = 0.2, 5 in). Nothing stiffer can require more. `_size_span_floor(::TwoWay)` now uses the long span for ln (it used min(span, l2)) and β = long/short. `_size_slab!(::TwoWay)` passes no αfm because the beams are sized after the slab. Tests: 220 sizer, 13 building.

Open: αfm from the actual beam sections needs a slab → beams → slab pass. The steel-beam αf basis (bare Es·Ix or composite) is ENGINEERING JUDGMENT, not settled. The span passed in is still spans.isotropic, the panel diameter, which overstates ln.
