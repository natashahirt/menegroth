Grade-wall strips, and mats that carry a wall line, now check every ASCE 7 combination. The gravity resultant still sets the plan center.

FoundationLateralCases keeps the D, L, roof, wind, and seismic reaction vectors. A grade-wall base node is combined with node_foundation_actions, in the same combination order as a column support. Station order matches the gravity samples. A combination in net uplift is an empty leg vector at that index.

A straight wall stays centered on the gravity (D+L) resultant: local x0 = Lf/2 − sbar. Each service combination must satisfy ACI 336.2R §3.2.1 Eq. (3-1) with q_max ≤ qa and q_min ≥ 0. If the resultant walks along the wall, the footing lengthens about that same center; if pressure or across-width eccentricity governs, it widens. A corner keeps its end overhangs and only widens. Extending one free end of an L or a T would move the centroid. If an edge still lifts after widening, the design throws. Eq. (3-2)–(3-4) partial contact is not applied. The rigid section envelopes each strength combination's moment, shear, peak pressure, and tensile steel.

A mat's combination resultant is the enclosed columns' actions plus that combination's wall-sample vertical forces. Equal overhang, so the centroid stays the center of the column and wall box. If any enclosed column has no stored actions, the wall cases are withheld rather than mixing gravity column Pu with a seismic wall line.
