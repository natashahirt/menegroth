# Reinforcement bar properties and cover

Longitudinal reinforcement uses #9 bars (As = 1.00 in.2, db = 1.128 in.); stirrups use #3 bars (Av per leg = 0.11 in.2, db = 0.375 in.). Clear cover = 1.50 in. per Table 20.6.1.3.1; maximum aggregate size = 0.75 in.
