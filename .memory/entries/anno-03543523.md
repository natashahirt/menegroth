User confirmed (2026-11-06) after the explanation: leave node_rotation out of the viewer scene.

Correction to the parent decision: the .mgdesign archive does not store the rotations. It stores the design. Rotations come back only by rebuilding the analysis model and solving, which is how a scene is rebuilt anyway. The viewer reads node_rotation today, swaps Y/Z, and never uses it. Slabs and walls move by node_displacement. Column and beam bending uses element_local_dof. Dropping the array saves 251 KB per design on the office and changes nothing on screen. A later feature that needs rotations can add them back as an optional array.
