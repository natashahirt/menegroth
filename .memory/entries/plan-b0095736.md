Four lateral-analysis approaches, selectable on one building and compared on the same checkers. Only the force split changes between them.

1. Whole building as one unit. The combined frame-and-wall model. Forces follow stiffness. This is the reference. Socket name: building unit. Not implemented in Phase 7; selecting it refuses.
2. Walls are the seismic force-resisting system and the frame is gravity framing. Phase 7 implements this one. Beams that frame into columns are modeled with pinned bending ends so the frame does not act as a moment frame. Column base fixity is unchanged: a fixed base still leaves a cantilever-column stiffness, which is reported, not hidden. Frame members are checked for the wind and seismic combinations using the forces the analysis assigns. For Seismic Design Category D, E, or F, components not in the seismic force-resisting system must also satisfy deformation compatibility.
3. Walls sized alone for a stated share of the lateral load (for example 50%). An explicit labelled mode, never a default. Not a design unless something else is checked for the remainder. Socket refuses until implemented.
4. Outriggers: core, outrigger or belt truss, and perimeter columns. Later. The intended study is how the load path moves across plausible stiffnesses (core cracking, truss and column axial stiffness, foundation rotation, connection timing), not one elastic answer. Socket refuses until implemented.

Phase 7 also, inside the beam and column fixed-point loop: pick the cheapest passing vertical and horizontal reinforcement for each pier from a discrete list (reinforcement does not change stiffness, so the choice is exact for a given thickness), and check the given thickness rather than searching it. Thickness, length, and layout search stay later.

Code basis for the gravity-frame check, not yet implemented as a numerical check: ASCE 7-22 §12.12.4 Deformation Compatibility for Seismic Design Categories D through F (corpus: asce-7-22, PDF page 195). Every structural component not included in the seismic force-resisting system in the direction under consideration shall be designed for the gravity load effects and the seismic forces resulting from the Design Earthquake Displacements (δDE) and the associated drifts per §12.8.6. Exception: reinforced concrete frame members not designed as part of the seismic force-resisting system shall comply with ACI 318 Section 18.14. Earlier notes that cited §12.12.5 for this provision were wrong; §12.12.4 is the section.

Pinning the beam ends is a modeling choice so the declared system matches the model. It is not a code instruction to use pinned connections.
