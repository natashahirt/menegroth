Locked 2026-11-03 with the user.

Extent: one shell model per story, holding every slab and beam on that floor. All slab outlines go into one mesh, with the slab boundaries as interior constrained edges (the multi-cell slab path), so neighbouring slabs share nodes and continuity over the beams is kept. Each element takes the thickness of the slab whose cell contains it.

Concrete beam: web only, below the slab, with its centroid offset from the slab mid-plane by a rigid link (Asap transverse eccentricity). The shell supplies the flange, so the §13.2.4 T-section (aci-318-11, page 244) is not added to the frame.

Steel beam: when SteelBeamOptions.composite is set, offset below the slab on rigid links. Otherwise bare steel at the slab mid-plane with no offset. ENGINEERING JUDGMENT, open: rigid links model full shear connection, which is stiffer than the I_LB of AISC 360-22 C-I3-5 used for partial composite.

Beam sections: the current sections first, then the shell is re-run once after the beams are sized.

Beam design keeps the tributary loads. The shell's beam forces are reported alongside, not used for design.

Frame elements run between adjacent shell nodes along each beam edge. Column stubs sit at the beam ends. Load is the factored pressure on the shell plus beam self-weight. The panel goes from not_analyzed to analyzed with the shell moment field. Bars come from the shared panel design layer.

Tests: reactions equal the load on the net area; a panel on stiff beams hogs over the beams; a long one-way panel matches the continuous strip; a panel with an opening meshes and solves.
