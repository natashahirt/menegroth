# F1(a) Default Flexural Resistance/Safety Factors

For all provisions in Chapter F, $\phi_b = 0.90$ (LRFD) and $\Omega_b = 1.67$ (ASD); the nominal flexural strength $M_n$ is determined per Sections F2 through F13.
