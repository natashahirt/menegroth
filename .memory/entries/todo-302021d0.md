# C2 — Metal roof deck

Wide-rib/roof deck spans between joists and is the **roof diaphragm** that delivers lateral load to the LFRS. No roof-deck model exists (only the `JoistRoofDeck` type shell).

**Build:** SDI roof-deck profile catalog + gravity capacity (span vs. load), and diaphragm shear/stiffness (SDI Diaphragm Design Manual) feeding Phase A4. **Depends on:** Phase E5 (SDI). **Couples to:** C1 (joists below), A4 (diaphragm), A6 (snow loads carried).
