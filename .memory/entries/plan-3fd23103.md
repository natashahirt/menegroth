User decisions (2026-11-06):
- Picking an option switches the WHOLE building to that solved design. A design choice changes the load path, so columns, footings and walls come from that design, never mixed.
- Right-click on an element lists only solved designs that differ from the current one in that element's axis alone. No unsolved combination is offered.
- Choices with no element anchor (f'c, load combinations, deflection limit) live in a Design section of the left panel.
- Production: both a sweep runner (list of parameter sets on one structure, one file) and append_variant!(path, design).

Format sketch:
- Header: geometry hash (existing params-free hash); a write with a different hash throws.
- axes: fields that differ across stored designs (from changed_param_fields), each tagged with an anchor kind (slab, column, footing, beam, wall, or none). The field-to-anchor table is explicit; an unmapped differing field throws.
- variants: params, stored summary (concrete, steel, carbon, max ratio), pointers to buffers, component records, design_trace.
- buffers: content-addressed, stored once; shared arrays dedupe automatically. Analysis mesh differs per floor system, so it is per variant unless identical.
- Each variant's .mgdesign archive kept beside the scene for rebuilds.

Viewer: switching keeps camera, cuts, mode; selection carries over by geometric key (column story + grid vertex, footing support position, slab cell set) or clears. Menu shows deltas only from stored summaries.
