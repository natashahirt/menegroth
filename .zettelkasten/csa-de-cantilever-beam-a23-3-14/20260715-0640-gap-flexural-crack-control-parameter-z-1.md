# GAP — flexural crack-control parameter z (10.6.1)

Crack control uses z = fs·(dc·A)^(1/3) per CSA A23.3-14 (10.6.1) with fs = 0.6·fy = 240 MPa, yielding z = 20,604.86 N/mm < 30,000 N/mm (o.k.); the z equation OCR is garbled and must not be transcribed.
