2026-11-08. Confirmed plan for the remaining rib-grillage work, in build order. No new floor type: a one-way or two-way topping, frame ribs, and a solid rectangle at the column.

1. Cleanup and API. One helper for the joist 1.10 Vc factor, with a test that punching never calls it. Add n_xi / n_eta beside analysis: grillage on the REST framing schema. A level that sends both a spacing and bay counts still fails. Bay counts apply only to four-sided panels.
2. Corpus lookups before new equations. ACI 318-11 §13.2.5 drop-panel size (aci-318-11). Effective inertia and long-term deflection, §9.5.2.3 and §9.5.2.5. Do not use the strength-model I_factor as a service stiffness.
3. Head geometry. Start from an input size. Classify the head as a drop panel or a shear cap. Split building beams at the head edge before the analysis model is built (reuse the joist landing cut). The piece inside gets solid_head_section. Put the head's own dead load on the frame, not a uniform rib-floor weight.
4. Punching, then grow. See the sibling decision. If any check fails, grow the head by whole rib modules, re-split, re-solve, and check again.
5. Benchmark against the StructurePoint waffle example (sp-de-two-way-waffle-slab-aci318-14): 3.32 in equivalent depth, stresses at both sections, exterior head failing.
6. Rib deflection from the grillage frame. A story that is all grillage stays off the story shell. Limit check stays with the beam checker; the number comes from the frame solve and the stiffness rules from step 2.
7. NLP ribs, at the existing rib-sizing call. §8.13.2 and §8.13.3 as constraints; re-check the snapped section; the 1.10 one-way increase only if that section still passes.
8. Placed bars and takeoff last, in detail_building, for ribs, topping, and the head. Topping bars are the one-way bars sized from the rib bay; a bay those coefficients do not cover still gets no bars.
9. Rebuild rib_bay.mgscene with heads and punching ratios. Re-run the seven-system regression with --fresh (the T-beam assertion edit was not re-run).

API can land alone. Head split blocks punching and deflection. NLP can run beside those. Bars last.
