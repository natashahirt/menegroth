# Phase B — Floor & slab system coverage

`StructuralSizer/src/slabs/types.jl` **declares** a dozen floor systems but only **flat plate, flat slab, and vault** have a real `_size_slab!` building-pipeline path. The rest (`one_way`, `two_way`, `waffle`, `pt_banded`, `composite_deck`, `non_composite_deck`, `hollow_core`, `clt`/`dlt`/`nlt`, `mass_timber_joist`, `joist_roof_deck`) either no-op or `error(...)`.

This phase converts those stubs into working pipelines, following the flat-plate pattern (init thickness → analysis → code checks → optimization → volumes/carbon). It is the floor-system half of covering DOE typologies; the framing half (joists, deck as diaphragm, roof deck) lives in Phases A & C.

Ordering note: one-way/two-way CIP are the highest-leverage (unlock beam-supported RC framing); composite steel deck is the DOE-office workhorse (couples to Phase A2 and Phase C). Mass-timber & precast panels depend on Phase E canon (NDS/CLT, PCI).
