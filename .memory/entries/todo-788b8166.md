Deferred 2026-11-03. A beam whose depth or width varies continuously along its length, such as a fish-bellied concrete beam, is a later project.

It does not need a new element type. The analysis socket is already one frame element per shell edge along the beam line, and each element takes its own section and its own centroid offset. ShellFrameBeam today stores one section and one offset for the whole line and stamps that pair onto every piece.

The later definition is a function of station. Sample it at each segment midpoint and write that section and that offset onto the element that already spans those two shell nodes. Each piece stays prismatic, so the shell edge length along the beam is the resolution of the curve. The offset of a piece is the slab half-depth plus the distance from the top of that sampled section to its centroid.
