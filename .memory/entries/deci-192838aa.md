Context: Soil presets (loose/medium/dense sand, soft/stiff clay) in StructuralSizer/src/foundations/types.jl already set ks (5,000 / 25,000 / 100,000 / 12,000 / 50,000 kN/m^3) citing Bowles 1996 Table 9-1, but Bowles is not in the corpus. ACI 336.2R §3.3.2 (p.7) allows ks from published sources (Bowles), a size-corrected plate test (Eq. 3-8), or ks = q/ΔH from elastic parameters; §2.2.3/§2.2.8 (p.5) say ks depends on footing size and cannot be reliably estimated for mats from plate tests; ACI SP-152 p.1 warns a single ks for a mat is wrong.

Decisions (user, 2026-11-07):
1. Add Bowles (Foundation Analysis and Design) to the corpus and verify each preset ks and its published range. Blocked until the user supplies the PDF.
2. A custom Soil without ks keeps requiring ks when a method needs it, with a clear message. No estimate from Es/qa until a grounded source is in the corpus.
3. The viewer shows ks-based results as 'deflection on springs', with the ks value and its source, not as 'settlement'.
