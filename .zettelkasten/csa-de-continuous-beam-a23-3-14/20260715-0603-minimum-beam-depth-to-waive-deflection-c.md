# Minimum beam depth to waive deflection computations (Table 9.2 / §9.8.2.1)

The minimum-depth check per CSA A23.3-14 §9.8.2.1 (Table 9.2) is applied; because the provided depth does not satisfy the minimum, deflections must be computed.
