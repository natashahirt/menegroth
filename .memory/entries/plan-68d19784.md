## Decisions
- Spandrels: Ch.9 beam when ln/h > 4 (flexure + §22.5 shear via beam checker). ln/h <= 4: §9.9.1.1 deep-beam definition (loaded one face, supported opposite) does NOT fit an end-supported spandrel; R9.9.1.1 says side-applied loads -> strut-and-tie (Ch.23). User chose to BUILD an STM spandrel check in this phase (diagonal strut + ties). Also check §9.9.2.1 (Vu <= φ10√f'c bw d) and §9.9.3.1 (0.0025 both ways). Ground every Ch.23 factor (strut angle limit, βs, βn, φ) in corpus before coding.
- Narrow segments: lw/t <= 3 is a column per ACI 2.3 'wall' definition (p.48) -> route to existing RC column checker (P-M, biaxial, slenderness). Add §22.5 one-way shear to the column path, sharing the beam implementation, plus tie detailing. Min ρ = 0.01 Ag (§10.6.1.1) applies.
- Opening extent: heads may reach the slab soffit. A full-story-height opening is refused (split the wall). Spandrel depth measured across the slab line (head of story i to sill of story i+1). No horizontal segment if none exists; pier hw then spans stories (conservative αc).
- No invented minimum pier width / spandrel depth numbers; column routing and beam/STM checks govern.

## Code grounding (aci-318-19)
- §2.3 (p.48): wall segment / horizontal / vertical / wall pier definitions; wall needs lw/t > 3.
- Notation (pp.23-24): hw = clear height of segment, lw = segment length -> §11.5.4.3 αc and §11.7.3.1 s <= lw/5 per segment.
- §11.7.5.1 (p.172): two No.5 (two layers) / one No.5 (single layer) around openings, anchored for fy at corners -> report as detailing + takeoff.
- R11.8.1.1: §11.8 slender-wall method not for panels with openings (guard only; stage does not call it).
- Corpus examples sp-de-multi-story-openings-aci19 and sp-de-tilt-up-wall-with-opening-aci19 are OUT-OF-PLANE ACI 551 design-strip problems, not in-plane pier validation.

## Steps
1. WallOpening(s0, z0, width, height, kind) on Wall; add_wall_opening!; gates: in bounds, no overlap, not in joined-corner clear zone, door sill = 0, not full story height.
2. Generators (punched, door, opening ratio, stacked/staggered, repeat up stack) emitting explicit openings through the same gates.
3. Holed mesh: breakline grid; s-breaklines unioned per wall stack, z-breaklines unioned per joined assembly; drop quads inside openings; tag triangles by segment.
4. segmentation.jl: vertical/horizontal segments; pier demands from horizontal cut through opening band; spandrel demands from vertical midspan cut; gate: sum of pier cuts = story cut.
5. Checks: piers via check_ordinary_wall with segment lw/hw; narrow -> column (+§22.5 shear); spandrels -> beam or STM; §11.7.5.1 bars.
6. wall_lateral_stiffness refuses walls with openings; report + visualization; tests (symmetric piers equal shear, equilibrium, door at corner refused, stacked mesh conforming, lw/t<=3 routed to column, STM spandrel hand case).
