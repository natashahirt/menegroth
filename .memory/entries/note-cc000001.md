# What: StructuralSynthesizer layout

Entry `StructuralSynthesizer/src/StructuralSynthesizer.jl` (`@reexport using StructuralSizer`, Asap unit registration, heavy precompile of design_building DDM/EFM + steel sizing).

- `building_types/` — geometry + analytical containers: `skeleton.jl` (`BuildingSkeleton`, `Story`, Meshes+Graphs), `structure.jl` (`BuildingStructure`: cells, slabs, members, supports, foundations, `TributaryCache`, `asap_model`, pattern-load caches, snapshots), `cells.jl`, `members.jl`, `foundations.jl`, `tributary_cache.jl`, `snapshot.jl`.
- `design_types.jl` — `DesignParameters`, `MaterialOptions`, `FoundationParameters`, `DisplayUnits`, per-element result structs, `BuildingDesign`, `DesignSummary` (typed `embodied_carbon_*`).
- `design_workflow.jl` — `prepare!`, `build_pipeline`, `design_building`, `capture_design`, `sync_asap!`, pre-sizing validation, column reconciliation, `_compute_design_summary!`.
- `core/` — `initialize!`, alternate `size!`, `snapshot!`/`restore!`, tributary accessors, skeleton lookup/build utils.
- `geometry/` — frame lines + slab validation/decomposition for DDM/EFM.
- `generate/doe/medium_office.jl` — `gen_medium_office` procedural skeleton.
- `analyze/` — slab/member/foundation ops + the Asap bridge (`analyze/asap/utils.jl`: `to_asap!`, `sync_asap!`, `build_analysis_model!`), tributaries (`compute_cell_tributaries!`, `compute_column_tributaries!`).
- `postprocess/` — embodied carbon (`ec.jl`) + engineering reports.
- `api/` — Oxygen HTTP + JSON schema/serialize + LLM chat/agent tools.

Note: there is NO `src/report_generators/` — those are tests; production reporting is `postprocess/engineering_report.jl` + `api/report_summary.jl` + `api/diagnose.jl`.
