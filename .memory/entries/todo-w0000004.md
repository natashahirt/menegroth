# S3 - FEM lateral (Asap shells)

The general answer for skew walls and irregular layouts.

- Wire `shell_elements` into `Asap.Model(nodes, frame_elements, shell_elements, loads)` in `to_asap!` (today they are created and then dropped).
- Mesh vertical walls as `ShellTri3` (reuse the `Shell(points, tris, section, :yz_plane/:xz_plane)` pattern) sharing nodes with floor diaphragm shells.
- Apply story lateral loads; recover per-wall in-plane `Nxy/Nxx/Mxx` via `ShellInternalForces`; integrate to wall `Vu/Mu` and feed the S1 checker.
- Optional second-order via Asap `solve_pdelta!` on the mixed model.
- **Validation:** add an Asap benchmark (single-story frame + wall shells + diaphragm under lateral load) and cross-check the wall shear split against the S2 rigid-diaphragm closed form.

Skew and torsion fall out of the FE assembly automatically - no projection math. Biggest lift (menegroth wall meshing + diaphragm wiring + wall-specific FE validation, none of which exist today).

## Progress (2026-07-13) — implemented & validated against the reduced oracle

Capability audit first: **Asap has everything at the library level** — `ShellTri3`
(membrane+bending, 6 DOF/node), mixed `Model(nodes, frames, shells, loads)`,
`process!`/`solve!`, `ShellInternalForces(...).Nxy`, stiff-shell `Diaphragm`,
`RigidLink`, `NodeForce`, `node.reaction`/`node.globalID`. The only gaps were
menegroth-side assembly, now built in `fem_evaluator.jl`:

- **Vertical wall meshing**: each `WallPanel` meshed into `ShellTri3` triangles on
  SHARED `Asap.Node` objects (reused across stacked stories + panels by
  plan/elevation identity → continuous walls). `Shell(corners,…)` is XY-planar so
  it is NOT used; triangles are built directly from shared 3D nodes.
- **Diaphragm**: per-floor stiff (E=1e12), near-massless fan-triangulated shell
  over that floor's wall nodes + a centroid master node → in-plane rigid. Story
  loads applied as `NodeForce` at the masters.
- **Base fixity**: base-elevation nodes fully fixed (cantilever).
- **Recovery**: drift from master-node displacements; per-wall shear at the base
  story recovered EXACTLY from nodal base reactions (equilibrium), projected onto
  the wall axis; upper stories via `Nxy` integration (first-cut, documented —
  centroid recovery undercounts squat piers).

**Validation** (`test/walls/test_walls.jl`, "FEM evaluator vs reduced-model
oracle", 6 asserts, 39/39 suite passes): symmetric 4-wall core — FEM X-walls
equilibrate the applied 100 kN (49.0+49.2), transverse walls ~0, torsion 1.0, and
FEM drift is the same order as the reduced model (ratio ~0.60; FEM stiffer because
the piers are squat, H/lw=0.75, where 2D shear behavior beats the 1D cantilever
formula — the expected higher-fidelity result). This closes the loop: the cheap
`ReducedDiaphragmEvaluator` is confirmed a good inner-loop proxy, and the FEM tier
is ready to validate S4 survivors.

**Remaining**: multi-story upper-panel shear recovery calibration (base story is
exact); `to_asap!` still drops diaphragm shells for the gravity model (separate
concern); optional P-delta via Asap `:pdelta`; and driving it from a real
building's `Wall`s via `to_wall_line`/`walls_to_panels`.
