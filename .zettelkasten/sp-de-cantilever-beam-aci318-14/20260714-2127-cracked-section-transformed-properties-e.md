# Cracked-Section Transformed Properties (Ec, n, B, kd, Icr)

Ec = wc^1.5·33·√f′c = 150^1.5·33·√4000 = 3,834.3 ksi; modular ratio n = Es/Ec = 29,000/3,834.3 = 7.56; B = b/(n·As) = 16/(7.56·4.00) = 0.529 in⁻¹; kd = (√(2dB+1) − 1)/B = 7.31 in; cracked moment of inertia Icr = b(kd)³/3 + n·As(d − kd)² = 8,120 in⁴.
