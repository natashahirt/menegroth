# Simplified (approximate frame analysis coefficient) method not permitted — span ratio > 1.2

The approximate-coefficient method of CSA A23.3-14 (9.3.1) requires ≥2 spans, uniform loads, prismatic members, factored LL ≤ 2× factored DL, and adjacent spans within 20%; here the adjacent-span ratio exceeds 1.2, so coefficients cannot be used and full moment-distribution analysis is required.
