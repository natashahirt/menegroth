# Commentary — Cb Values for Common Moment Diagrams

A User Note gives Cb=1.0 for equal end moments of opposite sign (uniform moment), Cb=2.27 for equal end moments of the same sign (reverse curvature), and Cb=1.67 when one end moment is zero, for doubly symmetric members with no transverse load between brace points; a more detailed Cb treatment for singly symmetric members is in the Commentary.
