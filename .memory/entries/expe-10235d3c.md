Follow-up to note-6e96d182 (T-beam MIP 724 solves, ~168s, flagged cacheable). The dominant sub-cost of discrete T-beam sizing is precompute_capacities! (φMn/φMn_neg/φVn/εt over the catalog), which StructuralSizer.size_tbeams re-ran every call because it re-instantiated a fresh RCTBeamSection catalog (new objectid) → 100% miss on optimize_discrete's cache + result-memo.

Key correctness insight: the ACIBeamCapacityCache stores ONLY demand- and span-independent section capacities. precompute_capacities! reads only material f'c + checker fy/fyt/Es/λ; the deflection/service-load fields (w_dead, w_live, shell_spans, defl_*) are applied per-demand in is_feasible, NOT baked into the cache. So ONE cache is valid across every member iteration whose spans/loads differ.

Implementation:
- StructuralSizer/tbeams.jl: new capacity_store::Union{Nothing,AbstractDict} kwarg on size_tbeams. _tbeam_capacity_key hashes catalog CONTENT (raw unrounded floats → bit-exactness) + checker fy/fyt/Es/λ + material fc(+fy/Es) + objective + n_max_sections. _tbeam_capacity_cache builds-or-reuses in the store and passes to optimize_discrete (revalidated via _require_cache_match).
- checker_cache.jl: added beam cache_matches(ACIBeamChecker,...) override (was defaulting to true) — length + fc/fy/Es gate.
- StructuralSynthesizer/size_beams.jl: per-struc WeakKeyDict store (_TBEAM_CAP_STORE, GC'd with struc), threaded as capacity_store into the serial batch loop. SS_TBEAM_CAP_NOCACHE=1 disables (A/B).

A/B (grid/x1y1 dense waffle, 30in pans, max_iter=12), same session:
- BIT-EXACT: total_ec=101495.538 kgCO2e, EC=211.449 kgCO2e/m², critical=Beam 1144 (min_reinforcement) r=1.0 — identical ON vs OFF, matches established baseline.
- sbc_mip 110.8s→65.4s (−41%); sb_one 225.4→188.8s; size_beams 311.3→281.8s.

Residual 65s sbc_mip = actual MIP solves + per-call catalog rebuild (accepted: content-hash needs the built catalog; precompute reuse is the dominant win; robust vs builder-internal coupling).

Tests: all T-beam optimization/tbeam/deflection tests pass. The 2 fails+1 error in concrete_beam/test_joist_ribs.jl 'check_tbeam_section reports what the sizer reported' are PRE-EXISTING (confirmed identical failure after git-stashing my 3 files on clean tree).
