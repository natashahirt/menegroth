Major workstream: turn menegroth's rich-but-fragmented components (grounded corpus, incremental simulator, trace layer, memory) into an AI-navigable design harness. Plan file: .cursor/plans/design_harness_architecture_f4925370.plan.md.

Core insight: most 2026 'harness' components are already externalized (memory, MCP tools, observability/trace, grounded corpus, simulator). Missing = the control plane that closes them into a perceive->reason->act->verify->remember loop, plus a UNIFIED design-state representation the agent can perceive (today fragmented across the computation DAG, DesignParameters, trace, and corpus/memory).

Literature anchors: AgentDSE (simulator-in-the-loop hypothesis-test-refine, ~2 OoM fewer sim evals, inspectable traces), Agentic Risk-Aware Set-Based Design (keep+prune candidate sets, CVaR), CHICO-Agent (persistent param->outcome KB), harness-engineering consensus (harness as first-class control plane).

Phases: P0 Unified DesignState substrate -> P1 explanation-layer grounding bridge -> P2 agentic set-based exploration loop -> P3 data-generation campaign. Parallel track: broaden the decision space (roadmap Phases A-H; Phase A ASCE7 loads highest leverage).

Cross-cutting principle (angelo export seam): build standalone in menegroth, NOT blocked on the in-progress angelo upgrade; only concession to future integration is a clean, domain-agnostic export (stable ids + explicit code/data/corpus refs) any external linker can index. No angelo-specific coupling.
