Runner: scripts/runners/diagnose_fea_unbalanced_mesh.jl (logs/fea_unbalanced_mesh.csv). 3x3 grid, 30 ft bays, 22 in cols, h=11 in, 2 stories.

Column stubs attach to one slab node; default FEA patch_stiffness_factor=1.0 makes the column footprint ordinary slab, so the stub moment enters the plate as a point moment (singular for plates).

max |Mub| (kN·m) at target_edge 0.08 / 0.10 / 0.15 / 0.20 / 0.30 m:
- pf=1 (default): interior 57/59/63/67/68; edge 197/211/233/237/312 (no convergence)
- pf=100: interior 86/84/83/83/85; edge 476/483/479/478/483 (converged within ~1.5% to 0.30 m)
- pf=1000: ≈ pf=100 (edge 484/491/485/485/494)
0.50 m breaks down for all pf (interior ~113).

Rigid footprint vs default: edge-column transfer moment ~2.0-2.4x higher, interior ~1.4x; panel deflection 20.2 → 15.5 mm; column M⁻ with band pinned to c changes only ~6%.
Reference: Mo ≈ 1085 kN·m, 0.3Mo ≈ 325 kN·m (rough hand calc).

Implication: default FEA likely under-predicts edge-column unbalanced moment (punching γv·Msc) and is mesh-dependent; rigid column footprint regularizes it. Not changed — needs user decision.
