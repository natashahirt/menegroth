# Decision - rename to `menegroth` (2026-03-11/12)

**Context.** The project was originally organized around a `StructuralSynthesizer` / "structural_synthesizer" identity. During productization it was renamed to **menegroth** (`231099d1` "change to menegroth", `1edf7903` "changed to menegroth and updated documentation").

**Consequences.** Grasshopper component paths were migrated `structural_synthesizer -> menegroth` (`ff1ac311`), AWS deploy wiring and the docs were updated, and the Julia package that sits on top kept the `StructuralSynthesizer` module name while the umbrella repo/product became menegroth. This is why the repo is `menegroth` but the top package is still `StructuralSynthesizer` today.
