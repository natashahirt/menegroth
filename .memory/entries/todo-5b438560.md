# B1 — One-way slab pipeline

`OneWay` gets an ACI minimum-thickness init but its building-pipeline `_size_slab!` is a **no-op** (`slabs/sizing.jl`). This is the highest-leverage floor stub — it unlocks beam-supported RC framing (the base for two-way, and for beams carrying slab loads).

**Build:** one-way strip analysis (ACI 318 coefficients or continuous-beam FEA), flexure/shear/deflection reinforcement, and the **slab→beam load hand-off** with slab/beam iteration mirroring the flat-plate pipeline. **Corpus:** ACI 318 (already ingested). **Couples to:** the existing ACI beam checker (`members/codes/aci/beams/`).
