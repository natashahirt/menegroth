# Canon manifest — ACI 318-19 §11.5.3 simplified / empirical bearing wall

Dev-loop stage-1 deliverable for the remaining `todo-w0000008` thread: the
empirical/simplified axial method for a solid rectangular BEARING wall whose
factored-load resultant stays within the middle third of the thickness (small
out-of-plane eccentricity). Sibling of the §11.8 alternative method
(`note-w0000014`): §11.8 = tension-controlled laterally-loaded slender panel;
§11.5.3 = stockier, ~concentrically-loaded bearing wall, one closed-form knock-down.

## Canon gap + resolution (IMPORTANT)

The originally-assumed oracle `sp-de-bearing-wall-aci19`
(`DE Bearing Wall ACI 19 v1.0.txt`) turned out on inspection to be a **§11.8
alternative-method** case (precast panel, `Pu ≤ 0.06 f'c Ag`, P-Δ, Δs ≤ lc/150),
**NOT** a §11.5.3 empirical example. Web search confirmed all freely-available
StructurePoint "bearing wall" examples use §11.8 (spWall is FEM-based), and the
PCA Notes "Example 21.3" everyone cites is likewise the §11.8/§14.8 alternative
method — so **there is no independent §11.5.3 worked-example numeric oracle in
the corpus or freely online.** (User is sourcing a textbook example —
McCornac *Design of Reinforced Concrete* / Wight — to add as the independent
numeric oracle; see open thread.)

The **equation itself** IS grounded in the corpus: ACI 318-19 §11.5.3.1
Eq. (11.5.3.1) is the verbatim, unchanged predecessor ACI 318-11 §14.5.2
Eq. (14-1) (corpus: aci-318-11). Same house convention as `checker.jl` (cites
§11.5.4 verified against 318-11 §11.9.3).

## Governing clauses / formula

| Quantity | Clause | Value / form |
| --- | --- | --- |
| Nominal axial capacity `Pn` | **§11.5.3.1 Eq. (11.5.3.1)** = 318-11 Eq. (14-1) | `Pn = 0.55·f'c·Ag·[1 − (k·lc/(32h))²]` |
| Design strength `φPn` | **§11.5.3.3 → §21.2.2** | `φ = 0.65` (compression-controlled, tied) |
| Effective length factor `k` | **Table 11.5.3.2** | 0.8 braced+rotation-restrained; 1.0 braced+rotation-free; 2.0 not braced (cantilever) |
| Middle-third resultant | **§11.5.3.1** | `\|e\| ≤ h/6` (else use general method) |
| Minimum thickness | **Table 11.3.1.1** | `h ≥ max(4 in, min(lu, lc)/25)`; exterior basement/foundation ≥ 7.5 in |
| Slenderness validity | **Eq. (11.5.3.1)** | `k·lc/(32h) < 1` (else bracket ≤ 0 ⇒ no usable capacity) |

`Ag` = gross area of the wall section considered (`lw·h`); `lu` = unsupported
horizontal length between lateral supports; `lc` = clear unsupported height.
The bracket is dimensionless and `Pa·m² → N` directly (no psi/in gymnastics).

## Applicability gates = HARD safety boundary

`check_wall_bearing_empirical` refuses (FAILED CheckResult, governing clause,
never a silent pass) when: net axial tension (`Pu < 0`, §11.5.3 is compression
only); `h` below Table 11.3.1.1 min (clause 11.3.1.1); `|e| > h/6` (11.5.3.1);
`k·lc/(32h) ≥ 1` (11.5.3.1). Otherwise strength governs (`Pu ≤ φPn`, ratio
`Pu/φPn`, clause 11.5.3.1).

## Validation strategy (no worked-example oracle → two-pronged)

1. **Independent hand calc of the closed form** (`test_walls.jl`, report §3B.1).
   Documented example — f'c=4000 psi, 8 in wall, 12 in strip, lc=15 ft, k=1.0,
   φ=0.65 → `k·lc/32h = 0.70313`, `R = 0.50562`, **Pn = 106.79 kip, φPn = 69.41
   kip** (pinned to `atol = 0.05 kip`, the primary regression guard). NOTE: this
   verifies the CODING of Eq. (11.5.3.1), not the equation choice (which the
   corpus 318-11 §14.5.2 anchors) — it is not a fully independent oracle.
2. **Asap FEA cross-check** of the two physical ingredients (`test_walls.jl`
   "Asap FEA cross-check", report §3B.2):
   - shell (membrane) model reproduces axial stiffness `E·Ag` to **<0.2%** —
     validates the `0.55·f'c·Ag` material/area basis;
   - frame beam-column model reproduces the elastic (Euler) buckling load
     `π²EI/(k·lc)²` to **<1%**, the ACI `φPn` sits at **≈0.12·Pcr** (a strength
     formula is intentionally a conservative fraction of elastic buckling), and
     both the ACI knock-down `R` and the FE buckling load fall off monotonically
     with height. NOT an "FEA ≈ capacity" claim — the FEA validates the
     ingredients + conservatism, not the strength number.

## Footguns

- `Ag` and `Pu` scale linearly; full-wall or per-strip both fine, but pass the
  TRUE unsupported horizontal length as `lu` for a narrow strip (default `lw`
  would collapse `min(lu,lc)/25` to the strip width → non-conservative min-h).
- Do not drop the `0.55` (material/eccentricity reduction) or `φ=0.65`.
- The method is compression-only and small-eccentricity-only; large `e` or net
  tension ⇒ use the general §11.5.2/§10 sectional method or §11.8.
