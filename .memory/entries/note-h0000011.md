# Note - automated nightly documentation audit (Mar-May 2026)

A cross-cutting practice visible throughout the history: a **CI/agent pipeline that audits docs for accuracy against the source nightly** and opens PRs. The log is dotted with **"Docs: nightly audit ..." merges (#8, #11-#16, #18, #21, #23-#27)** spanning March through May, plus a fix so the nightly "doesn't retrigger itself" (`6cc1b1a5`, 03-22).

**Why it matters for angelo.** This is prior art for exactly what the memory + zettelkasten layer generalizes: keeping a knowledge artifact (there, the docs site; here, the memory graph and the corpus zettelkasten) continuously reconciled with the evolving codebase. The doc audits target API schema, serialization/validation, sizer/synth pages, and ACI-column corrections most often.
