User decisions for the §I3.1b pre-cure check:
- Use SEI/ASCE 37-02 (corpus `sei-asce-37-02`) for the construction load combinations, Eqs. 2-2 and 2-3 (§2.2.3, PDF p. 16). Flag it as an older edition than the ASCE/SEI 37-14 that AISC 360-22 Commentary I3.1b cites, in code comments and in reported results, until 37-14 is in the corpus.
- Personnel and equipment load C_P comes from the working-surface class in Table 2 (§4.8.1.1, PDF p. 29). It is a user input that defaults to medium duty, 50 psf. The applied class should be reported in the results.
- Wet concrete is C_VML (factor 1.4) per Commentary C4.2; steel beam and installed deck are D.
