# D7 — Transfer structures

Buildings with **discontinuous columns/walls** (5-over-1 podium in F4, hotel transfer levels, column offsets) need transfer girders/beams that carry the discontinuity down to the frame below. Nothing designs these today.

**Build:** deep-beam / transfer-girder design via **strut-and-tie (ACI 318-11 Appendix A / 318-19 Ch. 23)** for concrete, and heavy plate-girder/built-up (D6) for steel; discontinuous-support load path + the special detailing / overstrength that transfer elements require. **Oracle:** corpus `sp-deep-beam-transfer-girder-aci318-14` (strut-and-tie transfer girder). **Couples to:** D6 (steel girders), F4 (podium), B-phase slabs above.
