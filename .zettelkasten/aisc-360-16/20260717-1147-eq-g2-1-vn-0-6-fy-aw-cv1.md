# Eq. G2-1 — Vn = 0.6 Fy Aw Cv1

$V_n = 0.6 F_y A_w C_{v1}$

$F_y$ = specified minimum yield stress, ksi; $A_w$ = web area $d t_w$, in.$^2$; $C_{v1}$ = web shear strength coefficient per G2.1.
