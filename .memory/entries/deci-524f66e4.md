Decided with the user (2026-11-06):
- **Stiffness**: bounding analysis per ACI 318-19 §12.4.2.4(c) (aci-318-19 p.183). Upper bound gross section; lower bound 0.35 x gross, borrowed from ACI Table 6.6.3.1.1(a) cracked wall (p.78) -- ENGINEERING JUDGMENT (no code gives in-plane diaphragm stiffness; R12.4.2.4 only says account for cracking). Both factors overridable. Elements designed for the envelope. ASCE 7-22 §12.3.1/§12.7.3 (p.179/184) require diaphragm stiffness and cracked concrete.
- **Plate**: slab shells act in-plane only (membrane). Gravity stays on the tributary path. Needs an Asap option to switch off plate bending.
- **Mesh**: slab mesh seeded with wall-top nodes so every wall node at the floor is shared.
- **Story force**: seismic as nodal forces proportional to seismic weight at each node; wind on windward and leeward floor edges by tributary edge length.
- **Accidental torsion** (§12.8.4.2 applies; C12.8.4.2 p.727): in-plane nodal forces proportional to node weight x distance from CoM, summing to the torsional moment.
- **Drift**: exclude diaphragm deformation per C12.8.6 (p.730): least-squares rigid plan motion (ux, uy, rz) fit to SFRS wall-top nodes, read at CoM; edge drifts for Ax read the same way.
- **P-delta**: first-order forces, require theta <= 0.10 (as flexible). Node-based K_G is a todo.
- **Order**: analysis first (mesh, loads, drift, wall demands) with tests, then diaphragm design (in-plane shear, chords, collectors; ASCE §12.10, ACI Ch.12) in the same step.
