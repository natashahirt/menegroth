Walk-back from "no perimeter upper frame": add a welded aluminum saddle ring on the X-base — long chords between ( ±a_top, ±b_top ) and short spreaders along the hinge-inboard A-lines. Ring nodes are interior_nodes of the core shell so the plywood bears along the rails, not only at four points. Stays with the base through the flip; both wood faces stay blank. Hinge fold clearance is preserved because the spreaders sit at x=±a_top, 3 in inboard of the hinge.
