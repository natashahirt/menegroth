# No worked examples in the J10–N specification window

This AISC 360-16 excerpt (Chapters J10–N plus Appendices/Commentary) contains no worked numerical examples — the Specification states provisions, not design walkthroughs. Machine-checkable test cases for these provisions must come from the companion AISC Steel Construction Manual and AISC Design Examples, which should be ingested as separate `role: examples` sources.
