# Phase E — Corpus & code ingestion

Per `.cursor/rules/corpus.mdc` + `code-accuracy.mdc`, **no factor, equation, or clause enters Julia without a corpus citation.** Several Phases B–D items are therefore **blocked until their canon is ingested** into `corpus/` (manifest `corpus/manifests/sources.yml`, pipeline `scripts/corpus/ingest.py` → `extract.py` → `corpus_promote.jl`).

Standards **currently absent** from the corpus manifest that the roadmap requires:
- **NDS 2018** (+ NDS Supplement design values) — timber. *Blocks D1, B6, C3.*
- **SDPWS 2021** — wood shear walls & diaphragms. *Blocks D1 lateral.*
- **AISI S100-16** (+ S240 framing) — cold-formed steel. *Blocks D2.*
- **TMS 402/602-16** — masonry. *Blocks D3.*
- **SJI** joist/joist-girder standard specs & load tables. *Blocks A1, C1.*
- **SDI** deck design manuals (composite + roof deck + diaphragm). *Blocks B7, C2.*
- **PCI Design Handbook** — precast/prestressed. *Blocks D4.*
- **AISC 341-16 + 358** — seismic detailing & prequalified connections. *Blocks seismic typologies.*
- **Full ASCE 7-22** wind/seismic/snow provisions (only load *combinations* are ingested/used today). *Blocks Phase A3/A6.*
- **ACI 318-19** full alignment (we mix 318-11 and 318-19) — reconcile edition drift.

Each ingestion item = add to `sources.yml` → ingest → (optionally) LangExtract → verify via the `corpus.*` MCP tools. This phase is deliberately front-loaded: it is the gate that keeps the whole roadmap code-accurate.
