The sized horizontal steel is drawn so the top of the steel meets the soffit of the nearest non-wall shell (node elevation minus half that shell thickness). The analysis node stays on the shell mid-plane. The picture therefore shows an eccentricity the solve does not have. Moving the analysis line would change stiffness and end moments, and that solver change stays deferred.

Columns, braces, solid heads, and solids already at or below the soffit are not moved. The slab itself stays centered on the shell node; this only changes the sized-steel picture.
