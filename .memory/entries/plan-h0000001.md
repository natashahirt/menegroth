# Project history & evolution

menegroth predates its angelo memory graph by ~7 months, so this subproject reconstructs the project's development narrative from the **git history** (283 commits, **2025-12-20 -> 2026-07-12**; ~243 by Natasha Hirt, the rest by Cursor agents/CI). It is organized as ten chronological **epoch** checkpoints plus a handful of pivotal **decision** nodes, cross-linked (`related_to`) to the package phases in `plan-a0000001` (Codebase architecture & reasoning).

Activity was bursty: a slow geometry-prototype start (Dec), a dense structural buildout (Jan-Feb), an enormous productization month (**204 commits in Mar** - API, Docker, AWS, Grasshopper, docs), an LLM-assistant/trace push (late Mar), embodied-carbon + experiment hardening (Apr), and structural refinements + a first MCP integration (May), before the angelo layer (Jul).

_Reconstructed 2026-07-12 by reading `git log`; `created_at` on each child is the historical date of the work, `updated_at` is the reconstruction date._
