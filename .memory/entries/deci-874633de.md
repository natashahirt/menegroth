User 2026-11-13, prompted by how Branch (branch3d.com) runs in real time. Decision: two fidelities behind one owner interface. Fast tier = closed-form demands where the geometry allows, coarse FEA elsewhere (unit-case superposition, mesh/factorization cached per layout, smeared orthotropic waffles/ribs). Full tier = today's sizer plus the verifier, run only on the shortlist. Checks and owners shared; fidelity belongs to the analysis service, so designers that embed their analysis (e.g. the flat-plate kernel's DDM/EFM/FEA) must be separated. DDM/EFM only within their limits. Each fast model carries a measured error band per element type and per system; shortlist = options whose bands overlap the best; only verified designs are reported as designs. Plan: Workstream F (F.1 code-structure audit ... F.7 exploration runner).
