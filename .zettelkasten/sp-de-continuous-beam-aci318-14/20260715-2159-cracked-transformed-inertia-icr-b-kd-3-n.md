# Cracked transformed inertia Icr = b(kd)³/3 + n·As(d−kd)² (PCA Notes)

Cracked transformed moment of inertia (rectangular section) per PCA Notes on ACI 318-11, Table 10-2. LaTeX: \( I_{cr} = \dfrac{b(kd)^3}{3} + n A_s (d - kd)^2 \). Symbols: \(b\) = width, \(kd\) = neutral-axis depth, \(n\) = Es/Ec modular ratio, \(A_s\) = tension steel area, \(d\) = effective depth. (Source: PCA Notes, not a numbered ACI 318-14 clause — no ACI clause alias.)
