# B8 — Nervi / isostatic-ribbed slab design

**Gap identified 2026-07-14.** A working **geometry prototype already exists**: `scripts/runners/run_nervi_vis.jl` generates stress-guided anisotropic rib fields where ribs curve to follow principal-moment trajectories (stress-guided anisotropic Laplace: ∇·((I+β·e⊗e)∇φ)=0; β=0 reproduces the orthogonal `Waffle` grid, β→∞ → Nervi character). Refs in-file: Nervi (1956) *Structures*; Mitropoulou et al. (2024) CAD 168. It shares the waffle module's polygon / isoparametric / MVC machinery. But it is **visualization/geometry only — no rib sizing, no reinforcement, no capacity checks.**

**Build:** promote the prototype from a runner into a design pipeline: (1) drive the rib-trajectory field from the actual FEA moment field (`flat_plate/analysis/fea/`) rather than a membrane-Poisson proxy; (2) size each curved rib as an ACI one-way/beam element along its trajectory (rib geometry per ACI 318-11 §8.13 / 318-19 §9.8, same limits as B7); (3) reinforcement + top-slab design; (4) material takeoff / carbon (couples to the EC accounting).

**Dependency:** builds on B3 (waffle analysis/design) — the isostatic layout is the anisotropic generalization of the orthogonal waffle. **ENGINEERING JUDGMENT flag:** the *rib layout* (following stress trajectories) is a research method beyond code; each *rib's* strength design must still trace to ACI §8.13/§9.8 + beam provisions. Keep the trajectory-optimization and the code-compliance design clearly separated.
