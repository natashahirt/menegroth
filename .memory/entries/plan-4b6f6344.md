Order. Each step has a gate; nothing later runs until it passes.

1. Identity. Pier = one straight leg in one story; owns its ShellTri3 list (kept by _mesh_wall_shells instead of dropped). Assembly = piers in one story that share corners. Store both on the structure. Gate: every :wall triangle belongs to exactly one pier.

2. Free-body cut. For a basic case u, sum K_e*u_e of a pier's triangles at its bottom nodes; project to V (in plane), M (about pier/assembly centroid), N. Assembly cut sums its piers. Gate: six-component equilibrium at every base and story cut for every basic case (walls + column/brace ends vs load above), one relative tolerance. A miss withholds that cut.

3. Mesh gate. Refine mesh_div and rows per story on an unsymmetric two-wall-plus-frame fixture until each wall's share of story shear stops changing. Pick the production mesh from that. Equilibrium does not catch this.

4. Corpus before code: cracked stiffness for analysis (ASCE 7-22 12.7.3 / ACI 318-19 6.6.3.1.1), rho in Eh (12.4.2.1, 12.3.4), Ax applied to torsion (12.8.4.3), orthogonal directions (12.5), P-delta on strength (12.8.7), effective flange width for an ordinary-wall assembly. Each becomes a required input or a refusal; nothing defaulted.

5. Gravity. Verify the load path to walls (zero-section :walls edges lump to end nodes; roof edge over the top wall). Add wall self-weight to D. Solve D, L, Lr/S/R unfactored as basic cases in one factorization.

6. Combinations. Basic resultants per pier and assembly: D, L, one of Lr/S/R, each wind case, each strength Eh case (x rho), Ev = 0.2 SDS D on N only. Apply each combination once. Keep (N, M, V) concurrent per case and combination.

7. Grouping. WallGroup keyed by input geometry and connectivity (length, thickness, height, concrete, assembly shape), not reinforcement. Group designed from the governing concurrent set across instances; forces stay per instance.

8. Checks and records. Existing ordinary checks: shear per pier, P-M per assembly, bearing. WallCheckRecord gets group, case, combination, demand, capacity, clause. Fixture: one isolated wall end to end; then a C-core only after step 4 flange width is settled.

Scope for the first pass: one isolated straight wall plus frame. Shared-corner walls refuse until assemblies and flange width exist.
