Confirmed grouping, coarsest first. Counts are the core office.

- :all — one thickness (today). 1 group.
- :story — one thickness per story, so a wall can step down with height. 4 groups.
- :wall_line — one thickness for a connected collinear run, every story. 7 groups.
- :pier_stack — one thickness up one pier, stories linked by wall_above on the same plan line. 13 groups.
- :wall_line_story — one thickness per collinear run per story. 28 groups.
- :pier — each pier. 52 groups.

:all stays the default and is the only grouping the jump implements. Any other value throws. A finer grouping changes relative stiffness, so in-plane shear and moment from one analysis cannot be frozen across groups. The next step is a size, re-analyze, re-check loop per group.

A wall line is collinear segments whose plan intervals touch or overlap within 1 mm. A gap keeps them apart. A pier stack is the existing wall_above chain that still shares a plan line.
