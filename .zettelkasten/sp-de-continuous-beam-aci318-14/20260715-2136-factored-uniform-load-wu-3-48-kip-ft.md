# Factored uniform load wu = 3.48 kip/ft

Service dead line load D = 2.19 kip/ft; service live line load L = 0.54 kip/ft (0.03346 ksf × 16 ft trib). Factored: wu = 1.2×2.19 + 1.6×0.54 = 3.48 kip/ft.
