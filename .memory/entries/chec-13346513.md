Phase 4b pre-cure moment shape has landed and is not committed.

When cell_dead_loads is a uniform line load on the beam, construction_span_demand scales the analysis dead-load moment and shear extrema by w_construction / w_ref. A pinned beam recovers wL^2/8 and wL/2. Fixed ends give wL^2/12. A propped cantilever's fixed-end shear scales to 5wL/8. The analysis model is already steel stiffness. A varying tributary width, a missing dead-load case, or a non-uniform line load leaves moment_model = :simple_span.

This scale assumes the construction load has the same layout as the analysis dead load. Personnel in a different pattern is not represented. Eq. A-6-5 still uses Cd = 1, because the stored shape is the extrema, not the inflection station.
