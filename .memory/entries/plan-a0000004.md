# StructuralSynthesizer

Top of the chain (depends on StructuralSizer + Asap). Generates building skeletons into a `BuildingStructure`, runs the `design_building` workflow to a sized structural system, exposes an Oxygen HTTP API (/health /status /schema /design /validate) plus agent-tool/chat surfaces, and computes embodied carbon (kgCO2e) in `postprocess/ec.jl`.

_Deep entries (skeleton generators, DesignParameters, the design pipeline stages, tributary-area analysis, the API/agent surface, carbon accounting) attach beneath this node._
