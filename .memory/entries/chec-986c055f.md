Area from unfactored force and qa, ACI 318-11 §15.2.2 (aci-318-11, page 271). Linear pressure is ACI 336.2R §3.2.1 Eq. (3-1) (aci-336-combined-footings-mats, page 6); an L uses the same line on the union of the leg rectangles (§4.2, page 7). A shared corner is one B by B square, counted once. A closed cell is refused. Kr below 0.5 still sends a straight wall to the beam on elastic soil and refuses a corner.

The split of that area into width and length is engineering judgment: center on the service resultant, round the width up to the increment, then lengthen equally if the factored resultant would leave the kern.

Eq. (5-2) still omits framed-member stiffness. The footing call does not receive beams. Tests 16/16.
