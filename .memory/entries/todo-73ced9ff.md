# D4 — Tilt-up & precast concrete

Tilt-up concrete walls + precast double-tees/columns are the standard warehouse, big-box retail, and parking-structure system. We have the out-of-plane slender-wall method (ACI 318-19 §11.8, `walls/out_of_plane.jl`) which covers the tilt-up **wall** in-service case — this todo extends to the precast **members** and erection cases.

**Build:** precast prestressed double-tee/beam/column design (PCI), tilt-up panel lifting/erection stresses + service (couples to the existing §11.8 method), and connection/bearing details. **Depends on:** Phase E6 (PCI). **Couples to:** B5 (hollow-core), `plan-w0000001` (tilt-up wall backlog todo-w0000008).
