# Phase 8 detailed plan — wall openings

Confirmed outline 2026-11-04 (plan-68d19784); this entry is the detailed version. Open decisions D1–D4 at the end must be answered before the step that uses them.

## Scope
In: rectangular openings in straight ordinary RC walls; in-plane design of vertical segments (as wall, or as column when lw/t <= 3) and horizontal segments (Ch.9 beam when ln/h > 4, strut-and-tie when ln/h <= 4); §11.7.5.1 opening bars.
Out: special walls (SDC D-F already refused); out-of-plane design of perforated walls (R11.8.1.1: §11.8 not applicable; stage does not call §11.8 today); non-rectangular openings; analytic stiffness of perforated walls (refused).

## Settled decisions
- Spandrels: ln/h > 4 -> Ch.9 beam (flexure, §22.5 shear). ln/h <= 4 -> §9.9.1.1 deep-beam definition (loaded one face, supported opposite) does not fit an end-supported spandrel; R9.9.1.1 sends side-loaded members to Ch.23. Build STM this phase.
- Narrow segments: ACI 2.3 'wall' needs lw/t > 3 (p.48). lw/t <= 3 -> column: existing P-M/biaxial/slenderness + new §22.5 shear + ties. §10.6.1.1 rho >= 0.01 Ag.
- Heads may reach the soffit. Full-story-height opening refused (split the wall). Spandrel depth measured across the slab line.
- No invented min pier width / spandrel depth.

## 8.1 Storage and validation (no structural effect)
Why skeleton: `_push_wall!` (wall_stacks.jl:208) rebuilds struc.walls on initialize, so openings on Wall alone would be lost. Mirror SlabOpening.
- New `building_types/wall_openings.jl`: `struct WallOpening; s0; z0; width; height; kind::Symbol end` (metres; s0 along wall from (x1,y1); z0 above story base; kind in :window, :door, :other).
- Skeleton: `wall_openings::Vector{WallOpeningSpec}` with `WallOpeningSpec(v1, v2, story, opening)`, keyed by wall edge vertex pair (orientation-normalized; s mirrored if the wall is built v2->v1).
- `Wall` gets `openings::Vector{WallOpening} = WallOpening[]`; `_push_wall!` copies matching specs. `split_tee_junctions!` re-bases s on each piece; an opening straddling the split point is refused.
- `core/wall_openings.jl`: `add_wall_opening!(skel, v1, v2, stories, opening)` (stories = Int or range, like add_slab_opening!).
- Gates (ArgumentError): finite positive dims; 0<=s0, s0+w<=L; 0<=z0, z0+h<=H_story; full story height refused; full wall length refused; door => z0 == 0 (1 mm); window => z0 > 0; overlap or touching (gap < 1 mm node tol) with another opening on the same wall refused; joined-corner clear zone (t_other/2)/sin(phi) at a joined end refused (checked when assemblies are known, at to_asap!).
- Tests: test_wall_openings.jl.

## 8.2 Generators (core/wall_opening_rules.jl)
Deterministic, return Vector{WallOpening} for (L, H), then applied over edges x stories through 8.1 gates.
- PunchedWindows(width, height, sill; count | spacing, edge_clear); Door(width, height; s0 | :center); OpeningRatio(target, width, height, sill; edge_clear): largest n with n*w*h/(L*H) <= target, refuse n=0.
- Alignment :stacked (same s each story) or :staggered (alternate half-pitch offset; depends on D1).

## 8.3 Holed mesh (analyze/asap/asap/wall_mesh.jl)
- Solid walls keep wall_panel_quads(8,8) unchanged (regression: identical forces).
- Walls with openings: `wall_panel_grid(s_lines, r_lines)`; s_lines = uniform 0:1/8:1 U opening s-edges of every wall in the same stack (wall_above chain on the same plan line) so slab-line nodes conform; r_lines = uniform rows U opening z-edges U (for a joined assembly) z-edges of every leg so corner-edge nodes conform. Lines closer than 1 mm snap.
- Drop cells whose centre is inside an opening. `_structural_pier_corners` bilinear mapping unchanged.
- WallMesh gains a cell map: triangle -> (wall_index, cell i, j) for segmentation. WallPierMesh still owns all of a wall's triangles.
- Tests: shared-edge node conformity (stack, corner), meshed area = gross - openings, solid regression. Extend scripts/runners/wall_mesh_convergence.jl to a wall with a window (pier shear share stable between refinements).

## 8.4 Segmentation (analyze/lateral/wall_segments.jl)
Per stack (walls on one plan line through all stories); coordinates (s, z) along the stack. Coarse grid: S_o = {0, L, opening s-edges}, Z_o = {stack base, top, story lines, opening z-edges}.
- Vertical segments: in every row that holds an opening cell, maximal runs of solid cells bounded by openings or wall ends; merge vertically consecutive runs with identical s-extent. lw = run length, hw = merged clear height (ACI notation: 'clear height of wall segment').
- Horizontal segments: in every column that holds an opening cell, maximal runs of solid cells bounded by openings or stack base/top; merge horizontally adjacent runs with identical z-extent. ln = width, h = depth.
- A cell claimed by both: D1.
- Leftover cells: full solid rows (existing whole-wall check) and joint cells (no ACI provision; §11.7.5.1 bars; reported).
- design: vertical lw/t > 3 -> :wall, else :column; horizontal ln/h > 4 -> :beam, else :stm.
- `struct WallSegment; kind; stack; wall_indices; s0; s1; z0; z1; shells; design end`.

## 8.5 Demand recovery (wall_cuts.jl, wall_combinations.jl)
- Generalize `_cut_contributions` to a line (horizontal z=c or vertical s=c in the stack plane), using only the segment's shells and only nodes on the line within the segment extent.
- Vertical segment: cuts at bottom (shells above, current convention) and top (shells below, sign flipped). Report both as WallAction (N compression +, V along tangent, M about horizontal normal).
- Horizontal segment: cuts at s0 and s1 faces -> beam action (N along span, V vertical, M about wall normal).
- New gate: at the bottom line of each opening row, sum of vertical-segment bottom cuts (+ frame elements crossing) = story cut at that z (reuse check_story_cut_equilibrium's loads-above logic). A miss withholds that stack's checks.
- Known limitation: a node on a vertical cut line at a slab level lumps slab/diaphragm nodal force into the cut (one node tributary); bounded by the mesh-convergence test; documented.
- Combinations: `_pier_action_batches` with a segment-aware action function (generalized pier_wall_action); second order via the existing story stiffness.
- Whole-wall base check runs only when the wall's base row is fully solid; otherwise that row's vertical segments replace it.

## 8.6 Checks
a) Vertical :wall: check_ordinary_wall with lw = segment length, hw = segment clear height (§11.5.4.3 alpha_c, §11.6.2), at both end cuts. §11.7.3.1 s <= lw/5 when shear reinforcement is required (needs spacing, D2). Wall rho_l/rho_t = worst of its segments and solid cuts. Bearing §11.5.3 keeps lc = story height.
b) Vertical :column: RCColumnSection b = lw, h = t; rho walk 0.01..0.08 (§10.6.1.1); P-M via pm_rect.jl and biaxial.jl with out-of-plane Mo; member slenderness §6.2.5/§6.6.4 with lu = clear height (ground k and sway classification before coding; story P-Delta already in forces); §22.5 shear with axial by moving beams' `_φVn_with_axial` (checker_strength.jl:389) to shared ACI code; ties §10.7.6 / §25.7.2 (bar sizes D2).
c) Horizontal :beam (ln/h > 4): flexure §22.2 with chord As, min §9.6.1; shear §22.5; stirrups per D3.
d) Horizontal :stm (ln/h <= 4), new kernel StructuralSizer/src/codes/aci/strut_and_tie/:
- Truss: chords at tie centroid d_t from each face, z = h - 2 d_t. Panel count k = smallest integer with theta = atan(k z / ln) >= 25 deg (§23.2.7, p.442); k = 1 is a single diagonal; k > 1 adds vertical stirrup ties. Diagonal direction follows the sign of V per combination.
- Loads: end actions from 8.5 (M as chord couple +-M/z, V at end node, N split to chords); remaining span load (difference of end shears) lumped to top nodes. Determinate truss solved by joints.
- §23.3.1 phiFns >= Fus, phiFnt >= Fut, phiFnn >= Fus. phi Table 21.2.1(g) = 0.75: VERIFY on PDF p.391 (text extraction dropped the column).
- Struts Eq.23.4.1a Fns = fce Acs; Eq.23.4.3 fce = 0.85 beta_c beta_s f'c; beta_c = 1.0 (Table 23.4.3(b)(c), no bearing surface); beta_s Table 23.4.3(a): interior strut 0.75 by line (c) when Table 23.5.1 reinforcement holds (orthogonal grid 0.0025 each way, §23.5.2(a) spacing <= 12 in) else 0.4 line (f). Line (c), not (d), so Eq.23.4.4 does not apply.
- Nodes Eq.23.9.1 Fnn = fce Anz; fce = 0.85 beta_c beta_n f'c; Table 23.9.2 beta_n 0.80 one tie, 0.60 two or more; Anz per §23.9.4.
- Ties Eq.23.7.2 Fnt = Ats fy. Anchorage §23.8.2 reported as assumed (like §22.9.5.1).
- §23.2.9 -> §9.9.2.1 Vu <= phi 10 sqrt(f'c) bw d, §9.9.3.1 0.0025 both ways, §9.9.4 (§9.9.4.3 spacing <= min(d/5, 12 in)).
- Strut/node widths: D4.
- Validate the kernel on sp-deep-beam-transfer-girder-aci318-14 (ACI 318-14 factors in that test; 318-19 beta_s table differs).
e) §11.7.5.1 opening bars per opening (two No.5 two-layer / one No.5 single-layer), added to takeoff; corner anchorage reported as assumed.

## Open decisions

D2 (before 8.6) Detailing inputs (cover, distributed bar spacing, chord/stirrup/tie bar sizes) needed for STM geometry, beta_s line (c), §11.7.3.1, column ties: recommend a required WallDetailing input with refusal when missing; alternative: stated defaults.
D3 (before 8.6c/d) Spandrel shear reinforcement: recommend explicit closed stirrups + chord bars (wall vertical bars not counted); alternative: count wall vertical bars.
D4 (during 8.6d) Strut end width / node geometry at the spandrel-pier face: ground in R23.2.6 figures and the SP transfer-girder example, then bring to the user. Nothing coded until decided.
