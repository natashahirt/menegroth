Corpus-retrieved citations for the step-4 pluggable modules (joint design + AISC 341 seismic detailing). All verified via corpus MCP. Published editions to cite: **aisc-360-16** and **aisc-341-16** (NOT aisc-341-22-draft — watermarked, 'do not cite as code').

## HSS / truss panel-point joints — aisc-360-16 Chapter K
- K1 Eq K1-1 (p.205) — effective width Be for connections to rect. HSS.
- K2 + Table K2.1/K2.1A (p.206-207) — concentrated forces on HSS; local yielding & plastification; K2.3 (p.208) defers rect-HSS concentrated loads to Chapter J.
- **K3 + Table K3.1/K3.1A (round, p.208-211)** and **Table K3.2/K3.2A (rect., p.211-213)** — the core HSS-to-HSS TRUSS connection limit states: chord plastification, punching shear yielding, chord side-wall shear in gap, local branch yielding (T/Y/cross/K, gap & overlap).
- K4 (p.213-214) — HSS-to-HSS MOMENT connections. K5 Eq K5-1..3 (p.214-215) — welds to rect. HSS (φ=0.75 fillet / 0.80 PJP).

## Brace-to-gusset / splice bolted-welded — aisc-360-16 Chapter J
- J2.4 + Table J2.5 (p.178-180) weld strength; J3.6 + Table J3.2 (p.187) bolt tension/shear; J3.7 combined; J4.1/J4.2 (p.193) connecting-element tension/shear; **J4.3 Eq J4-5 BLOCK SHEAR (p.194)** `Rn=0.60FuAnv+UbsFuAnt ≤ 0.60FyAgv+UbsFuAnt`, φ=0.75; J4.4 Eq J4-6 (p.194) connecting-element compression (Lc/r≤25→Py else Ch. E); J4.5 flexure.

## Advisory slenderness — aisc-360-16 (ADVISORY, User Notes)
- **D1 (p.84)** — no max slenderness for tension; User Note L/r preferably ≤ 300.
- **E2 (p.91)** — User Note compression Lc/r preferably ≤ 200.

## AISC 341-16 seismic (MANDATORY) — aisc-341-16
- **A3.2 + Table A3.1 (p.52-53)** — Ry/Rt expected strength (A992 Ry=1.1; A500 Gr.C HSS Ry=1.3/Rt=1.2).
- **D1.1b + Table D1.1 (p.61-63)** — highly/moderately ductile b/t limits (λhd/λmd).
- SCBF: **F2.3 (p.111)** capacity-limited brace forces (tension RyFyAg; compression lesser of RyFyAg and (1/0.877)FcreAg; post-buckling ≤0.3×); **F2.5a (p.114)** members highly ductile (struts moderately); **F2.5b (p.114) brace slenderness Lc/r ≤ 200**; **F2.6a (p.110)** brace-connection required strength (expected tension RyFyAg/αs, expected compression 1.1FcreAg/αs).
- EBF: F3.3 (p.118-119) capacity-limited from adjusted link shear (Ry·Vn ×1.25 I / ×1.4 box); F3.4a (p.119) link rotation 0.08→0.02 rad; F3.5b Eq F3-1..13 (p.120-122) link shear strength + detailing.

## CORRECTION to deci-bd727faa (slenderness split)
My recommendation prose cited the SCBF mandatory brace limit as 'KL/r ≤ 4√(E/Fy)'. That is the OLD 341-05/10 provision. **341-16 §F2.5b sets Lc/r ≤ 200** — which numerically EQUALS the §E2 advisory compression value, but is MANDATORY for SCBF braces (and comes with §F2.3 capacity-limited forces + §D1.1 b/t ductility, which the advisory §E2 limit does not). The split decision stands; only the 341-16 clause/number is corrected. The step-4 seismic module enforces §F2.5b (p.114).
