User chose the slab rule for footings: εt ≥ 0.005 (ACI 318-11 §10.3.4, page 142), and the depth search adds thickness.

- required_reinforcement gained a `φ` keyword (default 0.9).
- _footing_tension_As wraps it with the footing's ϕ_flexure and returns Inf when the section is inadequate or not tension-controlled. This replaces the lever-arm iteration, whose 0.5d floor hid an over-stressed section.
- _flexural_steel_footing throws on Inf.
- _footing_flexure_ok joins every depth search: spread (_depth_passes), strip (inner h loop via _strip_flexure_pairs: longitudinal peaks and each transverse band), rigid mat (strip moments moved before the loop), Shukla (_shukla_flexure_pairs, used by the loop and Step 5), and Winkler (in-loop column-strip totals).
- All reference-validated footing tests are unchanged. A small ϕ_flexure test shows depth growing past the 31 in shear answer.

Also fixed, each with a test:
- DDM §13.6.1.4: a throwing offset check becomes a violation (_guarded_offset_violations), so DDM is not used unverified.
- load_routing: a cell face with no edges throws (_require_face_edges).
- NLP multi-start: the x0 fallback is marked :infeasible unless it passes the feasibility check (_multistart_fallback).

Open, not changed: _create_cell_tributary_loads! still returns no loads when cell_edge_tributaries is nothing for a non-grade cell.
