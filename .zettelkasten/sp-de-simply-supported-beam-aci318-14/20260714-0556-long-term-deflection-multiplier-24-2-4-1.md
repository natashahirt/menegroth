# Long-term deflection multiplier (24.2.4.1.1, Table 24.2.4.1.3)

Additional time-dependent deflection uses the multiplier λΔ = ξ/(1+50ρ') (24.2.4.1.1), with the time-dependent factor ξ from Table 24.2.4.1.3; for a sustained load duration of 60 months or more ξ = 2, and ρ' = 0 is used conservatively, giving λΔ = 2.
