Save a finalized BuildingDesign so a later process can call to_asap!, stamp the sized frame sections, build_analysis_model!, and build_scene without design_building.

The file is a versioned Julia serialization of the design, not design_to_json and not snapshot!. The solved analysis model (design.asap_model) stays out, so a scene-mesh change is picked up on rebuild. The design-phase frame model is also left out; each skeleton edge keeps an explicit section record (A, E, G, Ix, Iy, J, ρ, Ay, Az, Ψ) that is stamped onto the frame to_asap! rebuilds. Tributary loads, rigid links, the wall mesh, and analysis caches are solver state and are cleared for the write, then restored on the live object.

Header: magic MGDS, format version 1, then the archive (format version, git commit, Julia version, StructuralSynthesizer / StructuralSizer / Asap versions, frame records, design). Load throws on a format, Julia, or package-version mismatch. The git commit is recorded and not checked, because the point is to reload under newer scene code.

Checked on a small flat-plate building, not the office. The office runner writes the .mgdesign beside the .mgscene on its next run; that run is not part of this work.
