# Web compression buckling resistance factors (§J10.5)

For the web compression-buckling limit state (§J10.5), the available strength uses φ=0.90 (LRFD) / Ω=1.67 (ASD). When the pair of compressive concentrated forces is applied less than d/2 from the member end, R_n is reduced by half.
