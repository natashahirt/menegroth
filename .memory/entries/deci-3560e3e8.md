A wall that the seismic :skew test (1e-8, the same test as nonparallel_system_elements) calls skewed is ASCE 7-22 Table 12.3-1 Type 5 (corpus asce-7-22, PDF p. 180). governing_diaphragm_span_depth returns that flag. resolve_auto_diaphragm appends 5 to a copy of diaphragm_irregularities and does not modify the caller's vector, and does not invent types 1–4.

The skewed wall is left out of the axis-aligned lines. An axis with fewer than two lines is skipped. Two or more skewed walls parallel within 1e-8 form a family: the span is the perpendicular distance between their lines and the depth is the floor-outline width along that direction (C12.3.1.3's distance between lines of vertical elements, applied off the orthogonal axes). One skewed wall with no parallel partner defines no span. The measurement throws only when no direction yields two lines.

Only the walls passed in are measured. resolve_auto_diaphragm passes the seismic-system walls when params.lateral is set, so a gravity wall is not Type 5. With no system, every wall is measured.

The flexible collector model is unchanged: its ties still run on a global plan axis and still refuse a skewed wall. The semirigid mesh already shares skewed wall-top nodes.

One diaphragm model still covers the whole building.
