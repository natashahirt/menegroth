# A3 — ASCE 7 lateral demand generation & diaphragm assembly

**The central analysis gap.** ASCE 7-22 load *combinations* are defined (`StructuralSizer/src/loads/combinations.jl`) but **never populated with nonzero wind/seismic**; `to_asap!` builds a frame-only model; diaphragm shells are *created but not assembled* into the solved model; `SiteConditions` fields exist but are unused. This todo makes lateral demands real.

**Build:**
- **Wind (ASCE 7 Ch. 26–30):** MWFRS pressures from basic wind speed, exposure, gust, GCp → story forces.
- **Seismic (ASCE 7 Ch. 11–12):** ELF base shear (Ss/S1, site class, R, Cs, k) with vertical distribution; MRSA as a later option.
- **Assemble diaphragms** into the Asap model (shells currently dropped) and apply story lateral loads.

**This is the demand-generation half that the wall/lateral program `plan-w0000001` (S2/S3) explicitly defers.** Coordinate: this todo feeds S2 (rigid-diaphragm distribution) and S3 (FEM lateral). **Depends on:** Phase E7 (full ASCE 7-22 wind/seismic canon). Validate against a worked ELF + wind example.
