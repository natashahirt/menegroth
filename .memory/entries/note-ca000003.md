# How: coordinate system, DOFs, solve contract

Global axes `globalX/Y/Z` in `Asap.jl`. **6 DOFs per `Node`**, ordered `[ux, uy, uz, θx, θy, θz]` and stacked per node in global vectors; `TrussNode` has 3 translational DOFs. Shell `ShellTri3`: CCW corner order defines +Z element normal, 6 DOFs/node. Default gravity / area-load direction is `(0, 0, -1)` GCS.

Frame elements: local x = start->end; 12x12 block-diagonal rotation `R` from direction cosines (special-cased when local x ∥ global Y); natural-deformation stiffness formulation (Argyris) for conditioning; optional eccentric connections transform K. Bernoulli-Euler vs Timoshenko is selected by `Ay=Az=Inf` (default) vs finite shear areas.

**Solve invariants** (`Model/analysis.jl`): `process!` must run before `solve!` (sets `processed`, builds sparse `S`, load vectors). Frame/mixed solves use `P - Pf` (fixed-end force correction); shell-only uses `P` only. Reactions: frame/mixed `S·u + Pf` at fixed DOFs, shell-only `S·u - P`. Cholesky/LDLᵀ factorization is cached on the model and invalidated on reprocess. Bridge elements are expanded into real nodes/elements in `processBridge!` before assembly. Analysis availability: FrameModel = static/modal/buckling/P-Δ/nonlinear; shell models = static/modal only; TrussModel = static/buckling.
