Diagnosed the member-stage throw with a live env-gated trace (`SS_DEBUG_MEMBER_SETTLE=1`, `scripts/runners/repro_member_settle.jl`). The small DDM equivalence fixtures converge in 1-2 rounds on the merged tree; the throw reproduces only on the **four-story FEA core office**. Two coupled mechanisms:

1. **Mode 1 — shrink oscillation.** `_fit_flat_plate_columns!` sets `shrink = uniform_column_sizing === :off` (the core office default) and in shrink mode does NOT raise the per-column floor to the installed size, so a column absent from `floors` shrinks freely. Trace: lower columns grew 16->20 (floored) while upper columns bounced 12->10 (unfloored) — undamped oscillation, 4 slabs stale forever.

2. **Mode 2 — stamp/installed asymmetry.** `designed_supports` is stamped from the slab's own design *workspace* (`find_supporting_columns(state)` in flat_plate/pipeline/api.jl = that slab's punching minimum), while `designed_above` is stamped from the main model. Axial/uniform column sizing grows a shared column past the slab's punching minimum; `_support_beats` refuses to shrink it; strict equality then flags the slab stale forever (e.g. stamp 20 beside installed 24).

**Fix (graph_builder.jl):**
- `_floor_columns_at_installed!(floors, struc)` pins every installed column into `floors` before the loop and at each round start -> the two-sided fit (which treats `floors` as a hard lower bound) can no longer shrink -> the stage is grow-only/monotone -> terminates (finite catalog, bounded by column cap). One initial right-size before the loop is still allowed.
- `_slab_checked_at_installed_columns` relaxed so a *grown* support column does not re-stale a **flat plate** (ACI 318-11 §11.11.2: larger column => larger b0*d capacity, critical perimeter moves out so Vu drops, ln shortens so transferred moment drops — strictly conservative). `designed_above` (stiffer column above attracts more unbalanced moment) and flat *slabs* (drop panels, §13.2.5) keep strict equality. This is also a speed win (no redesign/remesh for a conservatively-grown column).
- The budget throw is kept as a genuine-infeasibility backstop.

**Verification:** core/test_flat_plate_member_stage.jl = 299/299 pass (DDM, FEA, per_story, §10.12, and the designed_above-staleness test). Core office: member stage converges in 3 rounds (4->1->0 stale) instead of 48+throw; full `design_building` COMPLETES. design_graph equivalence test running.
