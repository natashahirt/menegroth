Landed the plan-axis defaults.

- `LateralDesign.plan_axis` is the default for both `Column.θ` and one-way floor spans. Column orientation and slab span stay independent. `θ = 0` (global X) adds nothing to Asap's default roll, so existing models are unchanged.
- Span direction, in order: `ScopedFloorOverride.span_axis`, then `DesignParameters.tributary_axis` when it is a direction, then the short side measured on the plan axes. Any bay shape is allowed. The direction is stored on the cell and is what load routing uses.
- `assert_story_walls_enclosed!` tests wall centers against the story floor faces. The axis-aligned box remains the drift plate.
- Parallelogram tests set the span axis three ways: along the sheared edge, perpendicular to it, and along global X.
- Slab helpers moved from `slabs/utils.jl` into `slabs/slabs/` so a cell can carry its own span axis. Story-shell beam demands are not part of this commit.

Known, not changed: at `θ = 0`, Asap `Ψ = π/2` makes `Ix` (`h = c2`) resist global-X sway, while c1 is the X dimension. Fixing that would rotate every existing column section by 90°.

Verified: skew plan walls 369/369; walls bridge and wall data model with that run earlier (75 + 84); ordinary-wall stage, checks, combinations, cuts, phase-5 assembly, and seismic gates 607/607.
