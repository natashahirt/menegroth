# Section properties for deflection — Ig, yt, n, Icr

Interior-negative rectangular section: Ig = bh³/12 = 16×24³/12 = 18,432 in⁴; yt = h/2 = 12 in.; modular ratio n = Es/Ec = 29,000,000/3,834,000 = 7.56; cracked transformed inertia Icr = 10,897 in⁴ (7-#8 at 2 in.; B = 0.38 in⁻¹, kd = 8.42 in.). (n and Icr per PCA Notes on ACI 318-11, Table 10-2.)
