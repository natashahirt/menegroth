# Minimum beam depth to waive deflection computations (Table 9.3.1.1)

ACI 318-14 Table 9.3.1.1 gives minimum depths for non-prestressed beams that, if met, allow deflection computations to be waived. Here the preliminary depth h = 24 in. is less than the computed minimum h_min = 25.94 in., so deflections MUST be checked. (Clause: 9.3.1.1.)
