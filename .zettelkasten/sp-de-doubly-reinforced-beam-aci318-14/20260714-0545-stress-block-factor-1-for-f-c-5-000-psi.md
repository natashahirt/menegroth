# Stress-block factor β1 for f′c = 5,000 psi (Table 22.2.2.4.3)

The equivalent-stress-block factor β1 is reduced from 0.85 by 0.05 per 1,000 psi above 4,000 psi, giving β1 = 0.80 for f′c = 5,000 psi per ACI 318-14 Table 22.2.2.4.3.
