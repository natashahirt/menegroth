# D1 — Timber & light wood framing

The single biggest material-system gap for residential/small-commercial DOE types. Today: `NDSChecker.is_feasible` **errors**, `GlulamSection` is a **STUB**, no lumber/LVL catalogs, `materials/timber.jl` has `TODO: Add timber presets`.

**Build (layered):**
1. **NDS 2018 member engine** — reference design values + adjustment factors (CD, CM, Ct, CL, CF, Ci, Cr...), bending/shear/compression-parallel/tension/combined for sawn lumber, glulam, LVL/PSL. Fill the `NDSChecker` and `TimberMemberGeometry` capacity path; add species/grade + EWP catalogs and timber material presets.
2. **Light wood-frame assemblies** — repetitive stud walls, joist/rafter floors (couples to A1/C3), headers/beams.
3. **Lateral (SDPWS 2021)** — wood **shear walls** (segmented + perforated) and **diaphragms** with nailing schedules; the wood analogue of the concrete wall program `plan-w0000001`.

**Depends on:** Phase E1 (NDS) + E2 (SDPWS). **Couples to:** B6 (mass timber), C3 (wood roof), F4 (wood typologies).
