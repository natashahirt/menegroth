# Angelo knowledge-graph program

Goal (per project owner): use angelo to (a) build more of menegroth off a knowledge graph, (b) capture the why/what/how reasoning in the code, and (c) link code to the design examples and building-code documents in `corpus/`. Plan: memory graph of the codebase first, then re-extract the corpus PDFs into a zettelkasten (a more sophisticated upgrade of the existing `corpus.*` pipeline), then synapse to cross-link code<->canon.
