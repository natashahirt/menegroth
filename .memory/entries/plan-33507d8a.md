Each materialized framing level is sized in its own size_beams! pass, bottom-up by (level, slab_idx), primary girders last, with a reanalysis between passes. A level's beam_options object is used whole; nothing means the building-wide options. Same level and the same options object share a pass. n_max_sections applies inside a pass.

Composite state is per beam: unshored children are a set, not one mesh-wide shored flag. A pass resets and reseeds only its own composite children. Shored beams stay composite in the dead-load factorization.

Story-shell material is the steel recorded on the beam at sizing, then the story-wide steel. sustained_live_fraction stays story-wide.

Catalog overrides are removed: FramingLevel.catalog_override, the API key, and MemberGroup.catalog_override. A restricted catalog lives on the level's beam_options (custom_catalog) or the catalog keyword of size_member_group!.

Out of scope: ACI 318-11 §8.13 joist geometry and the 10% shear increase, an SJI catalog, and mixed-material report labels (those still read params.beams).

Existing framed buildings size differently: girders see this iteration's joist sections.
