# Final stirrup design — 19-#4 @ 10.5 in., φVn = 71.11 kips

Using #4 @ 10.5 in.: φVn = φ·Av·fyt·d/s + φVc = 0.75×0.40×60×22/10.5 + 33.39 = 37.71 + 33.39 = 71.11 kips > Vu = 65.82 kips. OK. Stirrups can stop at x = 187 in. (where Vu = φVc/2). Use 19-#4 @ 10.5 in. o.c., first stirrup 3 in. from column face. (ACI 318-14 §22.5.1.1 & §22.5.10.5.3.)
