# D3 — Masonry

Masonry is not a first-class material (only referenced in fire docs / earthen vaults). CMU and brick bearing + shear walls define schools, standalone retail, strip malls, and many warehouse envelopes.

**Build:** TMS 402-16 allowable-stress or strength design for reinforced/unreinforced masonry — axial+flexure walls, in-plane shear walls, out-of-plane bending, lintels/bond beams, and material properties (f'm, grout, unit strength). Mirror the concrete-wall checker structure from `plan-w0000001`. **Depends on:** Phase E4 (TMS 402/602). **Couples to:** F3 (masonry big-box typologies).
