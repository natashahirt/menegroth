## Decision
Sign the fixed slab mesh off against the governing-design gate, not a per-element drift band (which the remesh violates against itself — see child experiment expe-176bd058). Keep the shape as the **full fixed mesh** (all columns get a cap-sized patch + ~1in fenced refinement; annulus out to `fixed_mesh_cap` re-tagged to slab E/h). Hybrid reverted.

## Sign-off evidence (full medium office, 3 floors, max_iters=10; logs/ab_fixed_mesh_signoff.log, task 2486)
- **Safety/validity**: all 3 floors FLOOR_DESIGN_SUCCEEDED under BOTH methods.
- **Governing design**: Floor 3 identical; Floor 1 one column 14->16 in (+1 discrete step); Floor 2 slab 10->10.5 in with perimeter columns 18->16 in. All within +/-1 size step / +/-0.5 in — the expected spread when two demand fields differ by < the remesh's ~15% corner noise (discrete path-dependence, not an error).
- **Speed (deterministic counters)**: factorizations 78 -> 58 (-26%), mesh builds 92 -> 56 (-39%). Wall-clock 1036 s -> 838 s this run (1.24x; ~1.5x on an unloaded box).

## Production status
`fixed_mesh` defaults to **false** — opt-in via `FEA(fixed_mesh=true, fixed_mesh_cap=30in)`. It does NOT reproduce the remesh design byte-for-byte (it picks adjacent, equally-safe discrete optima), so flipping the default is a product-output decision left to the user. Recommended default-on only for scale/large-building runs where the ~1.3-1.5x speedup and bounded mesh count matter and adjacent discrete designs are acceptable.
