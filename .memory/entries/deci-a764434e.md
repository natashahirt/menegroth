Design for deriving AISC 360-16 Ch.I composite effective slab width (b_eff, §I3.1a p.150) from the building's irregular tributary geometry. Supersedes the first engineer implementation (uncommitted working tree: StructuralSizer/.../composite/effective_width.jl tributary path + StructuralSynthesizer/.../analyze/members/composite_context.jl), which is to be REWORKED to this spec.

## Why the first attempt was rejected
1. It collapsed the per-side tributary extent with `moment_weighted_avg_depth` (mirroring Sizer `effective_flange_width_from_tributary`). That helper is NOT the production path — it's only in Sizer tests. The actual production T-beam default is `_compute_flange_params` (StructuralSynthesizer/src/analyze/members/utils.jl ~L2860), which collapses via MAX ENVELOPE (`tributary_width_envelope`) and explicitly flags per-station bf(x) as the preferred future. User states moment-weighted average was previously shown inaccurate for beam sizing.
2. Multi-edge: it rejected (ArgumentError) beams spanning >1 skeleton edge. The house engine `_assign_beam_profiles_from_edges!` already stitches tributary across ALL edges a beam spans into one `beam.tributary_profile`. Single-edge-only is inconsistent.
3. Scope confusion: b_eff is a CAPACITY/section property. Demand (loads->M,V) is separate and already exact (see below).

## Chosen design — per-station composite check that reduces EXACTLY to the standard prismatic case
- **b_eff(s):** parametric, piecewise-linear, from the polygon-vertex tributary (combined whole-beam, multi-edge). Apply §I3.1a caps per station: L/8 (span-constant), ½·spacing / edge from the LOCAL tributary at s. Reinforcement-axis-aware (inherited from the tributary pipeline).
- **Demand M(s):** REUSE the exact `Asap.TributaryLoad` moment field — `q_local` integrates piecewise-linear loads in closed form (`_fem_uniform_partial`/`_fem_triangular_partial`), recovered along the member via `accumulate_force!`. No Riemann; no new demand machinery. The existing 200-station grid is sampling of an already-exact field.
- **Check:** DCR(s) = M(s)/ϕMn(b_eff(s)). Governing station found by LOCAL 1-D optimization on the exact per-segment fields (grid-independent, exact-to-tolerance), NOT grid sampling. Reason numeric max is needed: Mn(b_eff) is nonlinear (PNA plastic solve, flexure.jl get_Mn_composite) so DCR(s) has no closed-form argmax — but both M(s) and b_eff(s) are exact closed-form per segment.
- **Negative moment / continuity: baked in now** (avoid later rework). Dispatch by sign of M(s): M+ -> AISC I3.2a plastic composite with b_eff(s); M- -> I3.2b steel + slab reinforcement (Asr within b_eff(s) via existing `extract_parallel_Asr`).
- **Deflection: use FEM δ** (continuity-correct, returned by `member_group_demands`) with a composite-stiffness correction. Do NOT use the simply-supported 5wL^4/384EI form in composite/deflection.jl — invalid under continuity.
- **Studs / partial composite:** v1 at the governing section with a continuity-ready interface. Full per-station stud/shear-flow accumulation deferred (ΣQn available at a station depends on studs between it and the nearer zero-moment point).
- **Reduction guarantee (must be a test):** constant b_eff + parabolic M ⇒ governing station = midspan ⇒ byte-identical to current scalar get_ϕMn_composite. Regular grid ⇒ identical to today's get_b_eff.

## Scope label: option A+ (per-station strength + neg-moment/continuity + FEM-δ; studs at governing section).
Citations to carry in code: AISC 360-16 §I3.1a (p.150), §I3.2a, §I3.2b (verify via corpus aisc-360-16).
