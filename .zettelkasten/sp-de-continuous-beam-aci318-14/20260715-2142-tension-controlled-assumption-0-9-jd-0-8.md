# Tension-controlled assumption (φ = 0.9, jd = 0.862d)

Design assumes a tension-controlled section: strength reduction factor φ = 0.9 and internal lever arm jd = 0.862d, verified after As is finalized. Verification: c = a/β1 = 6.09/0.85 = 7.17 in.; εt ≈ 0.0062 > 0.005, so the tension-controlled assumption is valid.
