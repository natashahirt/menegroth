# How: the design_building pipeline

`design_workflow.jl`:
```
prepare! (initialize! + column estimates + to_asap! + snapshot!(:prepare))
  -> run_pre_sizing_validation (fail-fast DDM/EFM/FEA applicability -> 400, not mid-pipeline)
  -> for stage in build_pipeline: stage.fn -> [sync_asap! if stage.needs_sync]
  -> harmonize_uniform_column_sizes!
  -> capture_design -> build_analysis_model! -> restore!
```

`build_pipeline` branches on floor type:
- `:flat_plate` / `:flat_slab`: (1) `StructuralSizer.size_slabs!` + `update_slab_volumes!` [sync] -> (2) `_reconcile_columns!` (slab single-floor Pu vs accumulated Asap Pu; grow columns via ACI pure-compression) [no sync] -> (3) optional foundations.
- `:one_way`/`:two_way`/`:vault`/...: (1) size slabs [sync] -> (2) `_size_beams_columns!` iterative loop [sync] -> (3) optional foundations.

`PipelineStage.needs_sync` avoids redundant full Asap reloads when a stage doesn't change topology/loads. `sync_asap!` pushes slab self-weight into cells, updates tributary-load pressures, re-solves Asap. Tributaries: `compute_cell_tributaries!` (edge, straight-skeleton or directed) and `compute_column_tributaries!` (Voronoi clipped to cells), cached in `TributaryCache` (single source of truth, keyed by behavior+axis). Optional checkerboard pattern loading builds a force envelope in Asap.
