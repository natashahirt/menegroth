# T-beam effective flange width (Table 6.3.2.1)

Effective flange width beff is the minimum of three limits per ACI 318-14 Table 6.3.2.1: bw + 2×8h (= 16 + 2×8×8 = 144 in.), bw + 2×(sw/2) (= 192 in.), and bw + 2×(ℓn/8) (= 130.5 in.). Governing beff = 130.5 in. Clause 6.3.2.1, page 7.
