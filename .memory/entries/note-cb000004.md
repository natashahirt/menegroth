# How: the optimization layer

Two solver families over shared abstractions (`optimize/core/`: objectives `MinWeight`/`MinVolume`/`MinCost`/`MinCarbon`, option bundles, `AbstractNLPProblem`):

**Discrete catalog MIP** (`optimize/solvers/discrete_mip.jl`): `optimize_discrete(checker, demands, geometries, catalog, material; objective)` picks one section per member group; `optimize_discrete_multi` for multi-material; `optimize_binary_search` for lightest feasible via monotonic search. Solvers: JuMP + **Gurobi** (preferred, thread-local env pool, warmed in `__init__`) with **HiGHS** fallback. Member API `size_columns`/`size_beams`/`size_members` in `members/optimize/api.jl`.

**Continuous NLP** (`optimize/solvers/continuous_nlp.jl`): problem types for RC columns (rect `[b,h,ρg]`, circular), RC/T beams, steel W/HSS columns and beams, `VaultNLPProblem` (rise+thickness), `FlatPlateNLPProblem` (`[h,c]` grid search with DDM moments + punching + deflection + bar sweep). Solver backends `:grid` (default), `:ipopt`, `:nlopt`, `:nonconvex` via `optimize_continuous(problem; solver=...)`. Slab API `size_flat_plate_optimized`, `optimize_vault` in `slabs/optimize/api.jl`. `members/optimize/smooth_pm.jl` gives a differentiable Whitney-block approximation for RC column NLP constraints.
