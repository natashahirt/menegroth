# Web panel-zone shear parameters (§J10.6)

Symbols for web panel-zone shear (§J10.6): P_r = required axial strength (LRFD or ASD); P_y = F_y A_g = axial yield strength of the column; d_c = overall column depth; t_w = column web thickness; b_cf, t_cf = column-flange width and thickness; d_b = overall beam depth; α = 1.0 (LRFD) or 1.6 (ASD).
