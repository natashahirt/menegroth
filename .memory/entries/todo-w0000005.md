# S4 - Layout optimization

Synthesize *where* walls go, not just size given walls. Capstone; synthesizer-level (StructuralSynthesizer), cleanly separated from sizing (StructuralSizer).

- Reference: **Zhang & Mueller 2017 (MIT)**, *Shear wall layout optimization for conceptual design of tall buildings* (`corpus_id: zhang-mueller-2017-shear-wall-layout-opt`) - ground-structure / topology optimization over candidate wall lines.
- Layout as a first-class, cheaply-mutable object: a ground structure of admissible wall lines, each with present/absent + continuous length/thickness; objective = elastic drift/torsion/stiffness, NOT full code checks.
- Optimize on the **cheap S2 closed-form evaluator**; code-check (S1) and FEM-verify (S3) only the near-optimal survivors.

The user flagged this space as **hard to optimize efficiently** - the efficiency strategy is captured upfront in `deci-w0000006` and must shape the `Wall` type and the lateral-evaluator interface starting in S1.

## Progress (2026-07-13) — optimization problem implemented

Done: `WallLayoutNLPProblem <: AbstractNLPProblem` (`walls/layout_problem.jl`) — gradient-based continuous topology optimization over a `WallCandidate` ground structure; SIMP density vars (`t = ρ·t_max`, `k = ρ^p·k_max`); `objective_fn = MinCarbon`; `constraint_fns` = per-story drift/torsion + per-wall shear proxy, all from the cheap `ReducedDiaphragmEvaluator`; solves via the existing `optimize_continuous(:ipopt)` (`solve_wall_layout`). Objective extensibility proven: `MinDrift` + `WeightedLayoutObjective` added as new `AbstractObjective`s only. Interface/monotonicity validated (`test/walls/test_walls.jl`).

Remaining for full S4: **candidate ground-structure generation** from real building geometry (admissible wall lines per bay/story); an end-to-end `:ipopt` solve on a real building with warm-start; and survivor hand-off to the S3 FEM tier (`todo-w0000004`) for verification. Status stays pending.
