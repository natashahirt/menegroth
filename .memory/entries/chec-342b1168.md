## What shipped
The FE self-weight influence kernel (proven to 1e-11 in expe-d7ec85aa) is now a production path that turns steel-column sizing in an indeterminate moment frame into ONE certified MILP instead of a self-weight ratchet. Default-off flag `DesignParameters.monolithic_column_selfweight` (byte-identical when off).

## Pieces
- **StructuralSizer** `LinearCapacityCoupling` extended with optional per-(target,source) influence coefficients `φ` (`influence::Union{Nothing,Vector{Vector{Float64}}}`, φ≡1 default = backward compatible). `_add_capacity_coupling!` folds `base[c] + Σ_k φ[c][k]·Σ_t w[t]·x[j,t] ≤ Σ_s cap[c][s]·x[i,s]`. `size_columns` gains a `coupling` kwarg forwarded to `optimize_discrete`.
- **StructuralSynthesizer** new `selfweight_coupling.jl`: `build_column_selfweight_coupling` assembles `φ[i][g]` via `Asap.linear_response` (one back-substitution per source group on the cached factorization) + forward axial recovery at each target's governing station; self term adds the element's own distributed-weight member-load part per unit area; `base_i = Pu_c_i − Σ_g A_g_cur·φ[i][g]`; per-section `cap` from bisection on `is_feasible`. Returns `nothing` (falls back to ratchet) outside the steel/discrete/single-material/full-load regime. Wired through `size_columns!` + `_member_iteration_pass!`/`_column_only_pass!`.
- Safety: monolithic MILP only GUIDES the section choice; the outer loop's held-check + `_verify_installed_design!` re-solve and re-check on fresh FE.

## Tests (all green)
- `test_capacity_coupling.jl` (StructuralSizer): 53/53. Added φ≡1 equivalence, φ-scaling monotonicity, negative-φ unloading, dimension validation.
- `test_monolithic_column_selfweight.jl` (StructuralSynthesizer): 68/68. Well-formed assembly, φ vs fresh re-solve (relerr 8.9e-14), flag-off byte-identical, 1-pass self-consistency on a 2-story×2-bay frame.

## Two test-harness bugs fixed (builder was correct)
1. **φ-reproduce test**: scaling a `GravityLoad.factor` reaches the DISPLACEMENT solve only through `process!`; `_solve_struc_model!` passes `reprocess=false` for an already-processed model, so the cached `P`/`Pf` were reused and the self-weight never redistributed — the test saw only the `m_dir` member-recovery term (exactly HALF the true sensitivity). Fixed by forcing `Asap.solve!(model, links; reprocess=true)` in the perturbation. Confirmed `Δu_pred == Δu_actual` to 5e-19 and `Δpred == Δtruth` to 8.9e-14 once reprocessed. The real sizing loop reprocesses on every section change, so `φ = σ + m_dir(self)` is exact in production.
2. **self-consistency test**: `member_group_demands` rebuilds `struc.member_groups` without re-stamping `.section`, so reading `member_groups[gid].section` returned `nothing`; now read the installed section from the group's columns.
