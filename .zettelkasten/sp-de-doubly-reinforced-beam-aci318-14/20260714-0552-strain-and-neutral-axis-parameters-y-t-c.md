# Strain and neutral-axis parameters (εy, εt, εcu, c, dt)

Defines the strain parameters — steel yield strain εy = fy/Es (Es = 29,000 ksi), the tension-controlled limit strain εt = 0.005, the concrete crushing strain εcu = 0.003 — and the neutral-axis depth c measured from the extreme compression fiber.
