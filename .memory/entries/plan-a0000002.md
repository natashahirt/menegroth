# Asap (external/Asap)

Base of the dependency chain (v0.2.2, author Keith JL). Provides the finite-element analysis engine and a Unitful-based unit system that the rest of the stack builds on. Uses Meshes / DelaunayTriangulation for geometry and SparseArrays for assembly. Downstream packages consume it as `using Asap`.
