A from-scratch office is already correct. Those three do not change v4.

1. Load the T-beam flange check. `_verify_tbeam_flanges` is already written in `analyze/members/members/tbeam_flange.jl`. It throws when a neighbor sized later is wider than `MAX_CATALOG_TBEAM_WEB`, because the clear-distance cap of ACI 318-11 §8.12.2(b) was then too large. `size_beams!` calls it, and `analyze/members/utils.jl` never includes the file, so vault designs die with `UndefVarError`. Include the file after `size_beams.jl`. Do not write a second check. Then rerun the vault cases in `test_design_graph_incremental.jl` that stopped on that name.

2. Put mat flexural bars on the same development loop as spreads and strips. Look up ACI 318-11 §15.6.3 and §12.2 in the corpus before writing the check. The critical section for the cantilever is the wall face; the available length is the clear lip already used for qu·lip²/2. Interior negative bars have the core box. A mat with columns and no walls uses the projection past the column face, the same length a spread uses. Order, already ruled: Eq. (12-1) with Ktr = 0 and the real cb, then a smaller bar, then a §12.5 hook whose tail fits the thickness, then a larger plan that repeats bearing, punching, one-way shear, and flexure. §12.2.5 is not applied. Dowel embedment stays the straight-bar check in the thickness; do not mix it with the flexural bar. `check_development=false` stays on geometry tests that pin a short end.

Before changing a plan dimension, compute ld for the v4 bars against the 0.990 m lip. The §12.2.2 No. 7+ shortcut is about 47 in and does not fit; §12.2.3 at (cb+Ktr)/db = 2.5 is about 28.5 in for a No. 8 and does. Use the length the footing code already uses. If that length fits, v4 does not grow and no office rerun is required. Tests: a lip that fails straight and hook grows the plan and rechecks shear and flexure; a lip that fits does not change B, L, or the bar size.

While touching the footing header, change the strip comment that cites ACI 25.4.2 to ACI 318-11 §12.2. Leave the detailing module's ACI 318-19 Table 25.4.2 citations alone; that module is the later edition on purpose.
