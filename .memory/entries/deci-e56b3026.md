User decision (2026-10-21): when DDM/EFM is not permitted (ACI 318-11 §13.6.1 limits, e.g. Voronoi or randomly perturbed column layouts), the default is to fall back to FEA rather than raise. Rationale: FEA is the code-permitted general method (equilibrium + compatibility), so the fallback is not overriding an engineering choice; erroring by default would make every irregular building fail.

Requirements: (1) the notice must be impossible to miss, not just @warn: a trace event, plus a result field recording requested method, used method and the §13.6.1 violations, surfaced in the report and API response; (2) a manual override, e.g. on_inapplicable = :fallback (default) | :error; (3) consistent on every path: pipeline, rule-of-thumb and the NLP optimizer (NLP hands off to FEA sizing, or raises under :error). Integration test: Voronoi and perturbed layouts must produce a complete traced FEA design with the fallback recorded. FEA strip definitions and punching on irregular plans are deferred to the citation sweep (Run 3) unless Part B finds a concrete problem. Implemented in fix cycle 11 Part B (eng_slab11, run-9099fb8f).
