Resolved the centroid-transfer sign ambiguity by grounding it rather than guessing. Reverted the interim conservative upper bound |M|+Vu·e to the REDUCTION |M|−Vu·|e| (floored at 0), applied per axis with e = (props.xc, props.yc).

GROUNDING: ACI 318-11 R11.11.7.2 references Vu and Mu to the critical-section centroidal axis c-c, so the moment reduces by Vu·e. This is the convention worked in the PCA/ACI example (46.65 → 37.81 kip·ft, a reduction; corpus: sp-de-two-way-flat-plate-aci318-14 p.42) and already validated against spSlab on the orthogonal edge/corner path via eccentricity_to_critical_centroid (deci-8ec247a3). An exterior column's gravity-reaction eccentricity opposes the unbalanced moment; a re-entrant or skewed corner is the same class (section centroid shifts toward the slab interior), so it inherits the identical reduction. The general sections just use the exact centroid offset (props.xc/yc) instead of the closed-form e.

WHY NOT conservative +: the earlier 10.3% 'swing' was merely the math range between + and −; the physics/code convention picks −, so the reduction is the accurate (not unsafe) value — consistent with the user's original 'accurate mapping' choice. For re-entrant the offset is tiny anyway.

AXIS PAIRING: M_about_x (stress in y) ← |Muy_val| − Vu·|yc|; M_about_y (stress in x) ← |Mub| − Vu·|xc|.

TEST: 'centroid-transfer is the pinned R11.11.7.2 reduction' now asserts the routed corner's vu equals the −Vu·e branch (v_sub) and brackets the swing. 72/72 green.
