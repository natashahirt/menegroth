Follow-on to the proving slice. Instead of only pre-settling demands with F0 (which still RATCHETS to a fixpoint), fold the linear self-weight gravity accumulation directly into the member MILP as one linear constraint per coupled group, solved once with a global optimality certificate.

Key idea: a column's axial load is LINEAR in the section-selection binaries (each section adds a constant A·L·ρg), and under a fixed member moment every section has a precomputable max axial capacity P_cap(s) (AISC H1 interaction, monotone in axial, inverted once). So the coupled sizing is a single MILP:
  base_i + Σ_{j∈sources_i} Σ_t weight_j(t)·x[j,t]  ≤  Σ_s cap_i(s)·x[i,s]
Both sides linear in x (exactly one x[i,s]=1), so the solver returns the globally optimal self-consistent design in ONE pass — no fixpoint iteration, and it may move sizes down as freely as up.

Implementation (Option A):
- New generic, material-agnostic struct LinearCapacityCoupling + _validate_coupling + _add_capacity_coupling! in StructuralSizer/src/optimize/solvers/discrete/coupling.jl (plain Float64 loads/caps over group/catalog indices).
- optimize_discrete gains a `coupling` kwarg (flag-off byte-identical; memo + the budget-style infeasible early-return both gated to include coupling). Allowed WITH n_max_sections (coupling is an exact in-MILP constraint, not a pre-screen, unlike the `feasible` mask). Infeasible (catalog too light) returns empty section_indices rather than crashing on extraction.
- Exported LinearCapacityCoupling.

Proving slice (scripts/runners/relaxation_frame_proving_slice.jl) now has a third MONO column: beams sized by superimposed flexure only (self-weight carried to columns, 2nd-order beam-flexure effect neglected so the ONLY coupling is column axial — identical physics to the ratchet). Builds P_cap by bisecting the same is_feasible predicate the MIP screening uses. Result on the 30-story/60-group/283-W/≤12-section frame: cold 4 → warm 2 → MONO 1 expensive solve; identical 19.6875 m³; self-consistency CERTIFIED (re-checked at its own self-weight); gap 0.136%.

Tests: new StructuralSizer/test/optimize/test_capacity_coupling.jl (17 tests): flag-off byte-identical, design-dependent load forces an optimal upsize, impossible load → graceful infeasible empty result, works with n_max_sections, dimension validation.
