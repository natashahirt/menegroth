# How: embodied-carbon accounting

`postprocess/ec.jl`. Core identity **`EC = Σ(volume × ρ × ecc)`** per material in each element's `MaterialVolumes` dict, in Asap's `kgCO2e` unit. Materials are sorted by a semantic key before accumulation for deterministic sums (avoids Dict-order float drift).

Volume sources: slabs (`slab.volumes` via `update_slab_volumes!` after `size_slabs!`), members (`volumes(beam/column/strut)` from sizing), foundations (`size_foundations!`), and fireproofing (`_compute_fireproofing_ec`: SFRM/intumescent coating on `ISymmSection` via `StructuralSizer.compute_surface_coating` + `coating_ec`).

Aggregation: `element_ec(volumes)` -> `compute_building_ec(struc, params?)` -> `BuildingECResult` (slabs/members/foundations/fireproofing + intensity kgCO2e/m²) -> `_compute_design_summary!` fills `DesignSummary.embodied_carbon_*`. Surfaced via API summary, `api/diagnose.jl` (per-element), agent tools, `engineering_report`, and `ec_summary`. `DesignParameters.optimize_for` includes `:carbon`, delegating to StructuralSizer's `MinCarbon` objective.
