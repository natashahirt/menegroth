# Crack-control reinforcement distribution z = fs(dc·A)^{1/3} ≤ 30,000 N/mm (§10.6.1) — eq GAP

Flexural cracking is controlled via z = fs(dc·A)^{1/3} ≤ 30,000 N/mm per CSA A23.3-14 §10.6.1 (with fs = 0.6fy = 240 MPa; here z = 15,425 < 30,000), but the printed formula line is OCR-garbled.
