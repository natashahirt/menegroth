## Cardenas simplified method (uniform distributed vertical steel)

Wall: length `lw` (in the plane of bending), thickness `h` (= section `t`),
uniform vertical steel area `Ast` over `lw`, ratio `ρl = Ast/(lw·h)`.
Factored axial `Nu` (compression +), factored moment `Mu`.

```
ω  = ρl·fy/f'c
α  = Nu/(lw·h·f'c)
c  = lw·(ω + α)/(0.85·β1 + 2·ω)              # neutral-axis depth
d  ≈ 0.8·lw                                   # effective depth (ACI wall convention)
εt = (d/c − 1)·εcu                            # extreme-tension steel strain
    → tension-controlled if εt ≥ εty + 0.003 → φ = 0.90
T  = Ast·fy·(lw − c)/lw                        # resultant tension (yielded tension zone)
Mn = T·(lw/2) + Nu·(lw − c)/2                  # moments about the compression resultant C
φMn = φ·Mn
```

Equivalent compact form (identical result): `Mn = (Ast·fy·lw/2)·(1 + Nu/(Ast·fy))·(1 − c/lw)`.
