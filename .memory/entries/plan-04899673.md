2. Wall service load is short, and the mat bearing check uses it. The factored model carries one `:wall_self_weight` area load on all 7,504 wall shells. The mat plan is sized from `Ps_total / qa`, so the stored bearing utilization of 80.3% used the short service load. Putting the missing weight back puts that utilization near 130%. Strength design uses `Pu` and already includes the wall weight. This replaces the old step 1.

3. Column steel is inside ACI 318-11 §10.9.1 (aci-318-11, p. 148): all 64 stored columns have ρg ≥ 0.01. The 24 "below 0.01" warnings are the section constructor warning on layouts that are built and then discarded. §10.8.4 (a reduced area, not below half the section; same page) is not implemented and was not needed for this design. The constructor now rejects ρg outside 0.01–0.08 (step 7). A column grown for punching is re-laid out when the same bars fall outside that window.
