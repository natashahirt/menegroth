# Walls with openings — pier/spandrel decomposition

The `WallSection` model assumes a **solid** rectangular pier. Real shear/tilt-up
walls have door/window openings, which split the wall into vertical **piers** and
horizontal **spandrels** (coupling beams) — each a segment with its own `hw/lw`,
demand, and ACI check. The corpus has two opening examples.

**Build:**
- Geometry: represent openings on a wall (`Wall` gains an opening list) and
  auto-segment into piers + spandrels (StructurePoint idealizes irregular
  geometry to rectangular boundaries — mirror that).
- Distribute in-plane shear/overturning across piers by relative rigidity
  (reuse the S2 `ReducedDiaphragmEvaluator` per-segment), then run the S1
  shear (done) + P–M (w0000007) checks on each pier; spandrel = coupling-beam
  shear/flexure.
- `hw/lw` per segment feeds the existing `wall_alpha_c` correctly (squat piers
  → αc up to 3.0), which is exactly why the αc transition was validated.

**Known-answer oracles** (corpus):
- `sp-de-multi-story-openings-aci19`
- `sp-de-tilt-up-wall-with-opening-aci19`

Depends on w0000007 (per-pier flexure) and reuses S2. Also the natural bridge to
the S3 FEM path, which handles openings by meshing around them.
