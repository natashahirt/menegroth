`scripts/runners/dual_highrise_rc_core.jl` (NZ stories, default 30). Upgrades `dual_highrise_drift_proof.jl` from stiff core-columns to a genuine dual system:

* **RC core = concrete shell walls** (ShellTri3, Ec=27 GPa, t=0.75 m) — a box of :wall triangles around the central bay, rendered in the scene via the new `include_shells`.
* **In-plane rigid floor diaphragm**: per-floor master = corner node (0,0); `RigidLink`s tie ux,uy,θz and RELEASE uz,θx,θy (release=(F,F,T,T,T,F)) so gravity axial shortening stays independent. Governor/participation/re-solve all run on the condensed GᵀKG master/slave system (links passed through).
* **Two lateral cases**, each force spread equally over all 16 column nodes so the resultant passes through the plan center (center-of-rigidity) — applying at one node would spin the rigid diaphragm (torsion=F·e). Seismic = ASCE 7-22 §12.8 ELF (Ta §12.8.2.1, Cs §12.8.1.1, k & Cvx §12.8.3); wind = illustrative (z/H)^0.4 profile at 0.6×Vseis. Criteria: seismic §12.12 story drift δxe≤Δa·Ie/Cd, wind H/400 roof serviceability. Frame sized to the envelope + strength floor.
* **§12.2.5.1**: bare frame via `Asap.solve(model,[case],links; exclude_shells=true)` at 25% base shear → finite drift ⇒ stable independent LFRS.
* One `.mgscene` per case (`dual_rc_core_seismic/wind.mgscene`) via `export_scene(...; resolve=false, include_shells=true)`.

Regime insight: a real stiff shell-wall core makes the system CORE-DOMINATED — the core controls drift, so the drift governor sizes the frame by its STRENGTH floor (not drift). (The earlier core-COLUMN proof is frame-dominated and exercises the drift half.) Together they span both regimes.

Two bugs fixed this session:
1. background_infeasible at 30 stories: frame at the catalog floor + a flexible core made core-only drift exceed the limit (unsizable background). Fix: thick core (0.75 m) so the first solve is feasible.
2. optimality resizer `weights w must be > 0`: weight read `el.length`, which is 0 until `process!`; recompute geometrically from node coords (`elen`). Also applied to steel_vol.

30-story result: twist 1.1e-7 rad (≈0, doubly symmetric), seismic max story-drift ratio 0.937 (governor 3 iters, 49.2 m³ steel), wind roof ratio 0.42, strength met, §12.2.5.1 bare-frame drift 0.035 m. Scenes 238 KB each, 240 wall triangles.
