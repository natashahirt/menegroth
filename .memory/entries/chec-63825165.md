Literal reading gives 1.0D + 0.2L0 (or 0.4L0). drift_live_load_factor returns L/L0 and its docstring does not say the 0.5 still applies. Needs a user reading. Px for θ also uses §12.8.6.1 loads.
2. §12.8.6.1 Exception: Eq. 12.8-6 need not be considered for drift (C12.8.6.1: 12.8-7 still applies). seismic_response_coefficient always applies 12.8-6, which is conservative for drift.
3. Eq. 12.8-14 story shear Vx = sum of Fi from x to n is not encoded.
4. Method 1 is not permitted where Exception 2 of §11.4.5 applies; the function does not check that (caller).
