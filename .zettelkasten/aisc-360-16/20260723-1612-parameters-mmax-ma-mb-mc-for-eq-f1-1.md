# Parameters Mmax, MA, MB, MC for Eq. F1-1

Mmax = absolute value of maximum moment in the unbraced segment; MA/MB/MC = absolute value of moment at the quarter point / centerline / three-quarter point of the unbraced segment (kip-in.).
