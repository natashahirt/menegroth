Decoding the full per-pass section trace (211062.txt) against mirror pairs:

- Pass 1-2 mirror twins change IDENTICALLY (e.g. beam 7 == beam 36, beam 8 == beam 35; groups {5,20,32,45} and {6,19,31,46} move together). So the handedness is NOT present at the first sizing pass.
- size_beams is called per-row with feasible=[[k] for k] (each demand row solved independently, deterministically). Identical demand row -> identical section. The uniform-stiffness test already proved x-mirror demands are numerically EXACT (Delta=0 across x=12). Therefore two symmetric groups with identical demands cannot diverge from the MIP alone on pass 1.
- Conclusion: the divergence must enter at some MID pass via a DISCRETE, x-odd (index/group-id-ordered) tie-break that gives two still-symmetric groups different-but-equal-cost sections; feedback (section->stiffness->demand) then locks it in and collinear bar-sharing + the upward ratchet pin the C2 pattern. Consistent with find-542bde3f (emergent) and find-48ce26cc (collinear sharing enforces C2).

GOTCHA for decoding the trace: beam indices are NOT stable across a run. solid_head_split.jl push!(struc.beams, piece) appends new beam pieces mid-run, so a static build-time beam-index->geometry map cannot decode the per-pass index-keyed trace. Pinning the exact seed pass needs instrumentation that records each beam's GEOMETRY (endpoints) alongside its section at each decision, not a post-hoc index map.
