# Effective horizontal length per beam = 42 in

Horizontal length of wall effective for each concentrated load (§14.2.4) =
smaller of: (a) center-to-center beam spacing `7 ft = 84 in.`; (b) bearing
width + 4h `= 10 in. + 4(8 in.) = 42 in.` ⇒ **42 in. governs**, so the gross
area used in Eq. 14-1 is `Ag = 8 in. × 42 in. = 336 in²`.
