# Web sidesway buckling resistance factors and cutoff (§J10.4)

For the web sidesway-buckling limit state (§J10.4), the available strength uses φ=0.85 (LRFD) / Ω=1.76 (ASD). The limit state need not be checked when (h/t_w)/(L_b/b_f) > 2.3 for a compression flange restrained against rotation, or > 1.7 when unrestrained.
