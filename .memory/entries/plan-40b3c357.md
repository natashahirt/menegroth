User approved 2026-11-26 (session on scale/throughput). Implements the keystone exact-ish FEA speed win: mesh a slab ONCE at the column cap with a fine (~1in) fenced annulus per column; column growth re-tags :col_patch triangles and takes the value-only update path instead of a full remesh (27-36s -> 4-6s per analysis; ~1.8-2x whole FEA run, more on cap walks). Unblocks #2 Woodbury and #12 value-only re-check.

Approach (confirmed against deci-202e97fd, which rejected re-tag at the 0.15-0.3m mesh but endorsed a fine fenced zone):
- build_slab_shell_mesh: cap-sized ShellPatch, refine_edge + edge-strip width from max_column_size (geometry-stable), fine ~1in fenced annulus around each column center covering cap + critical-section margin.
- fea_mesh_key: drop per-column c1/c2/shape; key the fenced zone by cap so growth stays on the update path.
- _update_and_resolve!: re-tag :col_patch triangles whose centroid is inside the CURRENT column rect before the existing by-id value-only E assignment (E_patch vs E). Stub still attaches at the single center node -> node numbering + sparsity unchanged.
- Meshing stays in Asap (ownership); triangle re-tag is slab-footprint geometry (StructuralSizer).

Phase 1 (autonomous, no production change): FEA(; fixed_mesh=true) opt-in; scripts/runners/ab_fixed_mesh_accuracy.jl on medium office 8x5x3 + 3x3 plate; report per-column punching DCR, face moments M-, final column sizes, slab thickness, stud decision, wall-clock; fixed-mesh vs conforming-remesh.

Phase 2 (gated on user tolerance sign-off): APPROVED band = punching DCR +/-2%, face moments +/-3%, governing design unchanged, with a REMESH FALLBACK when a column grows past its fenced zone. After measured drift is within band -> add the fallback gate, make it the flat-plate FEA default, verify member-stage golden determinism.

Safety: flat-plate punching is safety-critical (ACI 318-11 Ch.11/13). No production default flip without the measured-drift sign-off.
