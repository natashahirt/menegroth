User chose one growth rule (2026-11-11). Reverses the earlier rule that a failing check with no direction does not grow.

- A failing check that names a direction grows one bay across the outline edges facing it (unchanged).
- A failing check that names none grows every bay sharing a node with the head: one ring, corners included. On a rectangular grid that is the next whole module at a corner, edge, or interior column, which is what the corner fraction did. Growing only across edges would have turned a square head into a plus.
- Any step whose head would not be one piece with one outline throws ArgumentError, so the resolver marks it stuck instead of failing later in the section.
- resolve_column_head stops are :passed, :no_demand, :blocked, :ratio (:no_direction removed).
- Removed grow_rectangle_grillage_heads, _next_solid_head, grown_solid_head. A rectangle is a modular_rib_arrangement on resolve_arrangement_heads. check_rectangle_grillage_heads and snapped_solid_head stay: the building still checks the input fraction without growing it.

Result on the old rectangle fixtures (fixed column stubs, real moments): light 6x4 passes on the seed bays; the 8x8 wide case passes after 2 steps with heads of 1,3,1,1 bays (greedy worst-first, so a symmetric plan ends unequal); the narrow-rib heavy case stops failing. None of the current fixtures reached the ring step: every failing check named a direction.
