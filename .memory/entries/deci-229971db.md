When `get_ϕPn` is unavailable, we DELIBERATELY do **not** fall back to the unconservative gross-yield estimate (which would let an unsafe column read as OK). Design choices:

- **Narrow catch** — only `MethodError`/`FieldError` are caught; real bugs re-throw.
- On catch, axial/interaction ratios are set to a **NaN "UNVERIFIED" sentinel** with `@warn`.
- Because `NaN ≤ 1.0` is `false`, `result.ok` **cannot** pass; `governing_check → "axial_compression_unverified"`.
- A steel section with `material===nothing` (previously bypassed both branches → silently passed at ratio 0/ok=true) now routes to the **same UNVERIFIED sentinel**.

Rationale: in a safety-critical structural codebase, an un-computable capacity must surface as *not verified* (cannot pass), never as *safe*.
