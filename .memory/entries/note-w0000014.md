## Scope of this run

In-scope: the §11.8 alternative method for a **simply-supported, axially-loaded,
out-of-plane laterally-loaded slender wall** with a single central layer of
distributed vertical steel — applicability gates, second-order (P-Δ) moment
magnification, φMn, Mcr, and the service mid-height deflection with the ≤ lc/150
limit.

Out-of-scope (deferred): walls with openings (`todo-w0000009`), in-plane P-M
(`todo-w0000007`, done), special boundary elements (`todo-w0000010`, canon absent
→ HARD STOP), retaining walls (`todo-w0000011`). The general empirical/simplified
bearing-wall method (§11.5.3) has its own oracle
(`SP-DE-Bearing-Wall-ACI19.txt`) and can be a follow-on; this run targets §11.8.

## §11.8.1.1 / §11.8.2.1 applicability gates (ALL must hold)

- (11.8.2.1) constant cross-section, simply supported, max M & Δ at midspan,
  axially loaded, out-of-plane uniform lateral load.
- (a) cross-section constant over height.
- (b) section is **tension-controlled** (`εt ≥ εty + 0.003`).
- (c) `φMn ≥ Mcr` (design strength exceeds cracking strength).
- (d) `Pu ≤ 0.06·f'c·Ag` at the midheight section.
- (e) service out-of-plane deflection incl. PΔ `Δs ≤ lc/150`.

If any gate fails, the §11.8 alternative method is **not applicable** — the check
must report `not_applicable`/fail, NOT silently pass. (This is the hard safety
boundary of the method.)

## Service mid-height deflection — bilinear (Table 11.8.4.1)

`Ma = Msa + Ps·Δs` (iterate: Δs depends on Ma, Ma depends on Δs).
`Msa = ws·lc²/8 + Pa·e/2` (service lateral + eccentric axial, no PΔ).
`Δcr = 5·Mcr·lc²/(48·Ec·Ig)`, `Δn = 5·Mn·lc²/(48·Ec·Icr)`.

```
if Ma ≤ (2/3)·Mcr:   Δs = (Ma/Mcr)·Δcr
else:                Δs = (2/3)·Δcr + [(Ma − (2/3)Mcr)/(Mn − (2/3)Mcr)]·(Δn − (2/3)Δcr)
```

Converge Δs by fixed-point iteration; require final `Δs ≤ lc/150`.

## Notes / footguns

- The design "width" `b` is the tributary strip (15 ft here), NOT the full wall
  length; `As`, `Ig`, `Ag` are all per-strip. Keep `b` explicit in the API.
- `Mua` uses `Pua·e/2` (eccentric roof load applied at top → linear to zero at
  base → half at midheight), NOT `Pua·e`.
- `0.75` in `Kb` is the ACI stiffness-reduction factor (§11.8.3.1); do not drop it.
- Gate (b) tension-controlled and gate (c) φMn≥Mcr are **prerequisites** of the
  method, not post-hoc "nice to have" — enforce before trusting Mu.
- Deflection uses gross `Ec` and the bilinear Ig→Icr interpolation; the ultimate
  `Δu` uses the same `Kb` (Icr-based) as the moment magnifier — consistent.
