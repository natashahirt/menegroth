Settles the open hypothesis from expe-a8e1485d ("the lever is _fit's plan-AREA cross-size selection"). Built a read-only carbon analogue of the O4 probe — `flat_plate_column_oversize_carbon` — that, per column, scans the whole catalog within the size cap ordered by rebar-inclusive embodied carbon (MinCarbon, long.+transverse steel) and returns the global min-CARBON section passing member P-M + §10.12 joint + punching at the column's own final demands. This is exactly what a carbon-ordered `_fit` would install, so the probe is a read-only preview of Phase 2.

Sweep (scripts/runners/column_oversize_carbon_probe.jl), low-rise flat plate, RC_4000_60 / Rebar_60:
| config | CARBON reducible | plan-area reducible | min-carbon≠min-area |
|--------|------|------|------|
| 3x3 x3 | 0.5% (40/8591 kgCO2e) | 2.1% | 8/48 |
| 4x4 x3 | 0.0% | 1.5% | 3/75 |
| 5x5 x3 | 0.0% | 0.0% | 0/108 |
| 4x4 x2 | 0.0% | 4.5% | 6/50 |

GATE (threshold 1%): max reducible carbon = 0.5% → STOP. Phase 2 (carbon-ordered `_fit`) and Phase 3 (default flip) are gated OFF; NO production selection change made.

Mechanism (now proven, not asserted): within a plan size the catalog is ρ-monotone, and across sizes the installed section is already near carbon-optimal, so plan-area minimization already captures essentially all reducible COLUMN carbon. The handful of min-carbon≠min-area columns are top-story members that want to GROW (10→12 in) to drop ρ — the carbon lever is both tiny AND anti-footprint. The 1.5–4.5% plan-area 'slack' is NOT carbon slack: shrinking footprint raises ρ and carbon (consistent with expe-6dcbaa95: shrink-to-min-area increased carbon +4.8%). This positively confirms WP 2.5's rebar-inclusive objective already does the job for columns.

Real carbon levers live elsewhere: slabs/ribs (parallel agent), foundations, walls, or full Part-B cross-element redistribution — NOT column cross-size selection.

Validation: member-stage 299/299 PASS with the additive probe loaded; probe designed 4 buildings cleanly. Note: 6+-story sway frames throw `no finite k on Fig. R10.10.1.1 (ACI 318-11)` (sway column both ends ~pinned → infinite effective-length factor) — a pre-existing ACI-slenderness pipeline limitation, orthogonal; sweep restricted to 3-story and below.
