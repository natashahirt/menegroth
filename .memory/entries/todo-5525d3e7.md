# F1 — DOE typology → system capability matrix

Before building generators, produce the **matrix**: each of the 16 DOE commercial prototypes (+ residential) × the structural systems it typically uses (gravity framing, floor, roof, lateral, foundation, material) × which roadmap phase/todo delivers it. This turns “comprehensive coverage” into a checklist and lets us sequence Phases A–E by typology payoff.

**Deliverable:** a table (in a docs report + this memory subtree) that, per typology, marks each required capability as done / in-progress / todo-linked. Also decides the **default** structural system per typology (real DOE prototypes vary by vintage/climate; pick defensible defaults and flag them as engineering judgment). No code — this is the planning artifact that steers everything else.
