Asap.Model copies the supplied node list as-is and assigns DOF slots by list index. If the same Node object appears twice (typical when interior_nodes/bearings are also in get_nodes(shells)), make_ids! overwrites globalID on the second occurrence and the first six free DOFs have no stiffness — LU SingularException after RigidLink reduce. Dedup by objectid before Model(). _merge_shell_nodes only uniques newly added shell nodes, not the input list.
